# 小齊平先生の思想（継承する前提）【経緯】【教員】

取得日: 2026-09-28。出典: 小齊平授業方針（`docs/knowledge/teacher/`）、過去の会話ログ（本フォルダ）、本セッションでの利用者の発言。
案が白紙に戻っても、ここに書いた思想は引き継ぐ。個々の案（成果物名など）はここに書かない。

## 最上位

- 授業の目的は **AIビジネス能力**＝AIを使って他人の役に立ち、報酬を得られる能力。これにフルベットする【教員】
- 段階は **自分の役に立つ → 他人の役に立ち「ありがとう」をもらう → 1円でも報酬を得る**【教員】
- ビジネスとは、誰かの役に立ち、その結果として報酬を得ること【教員】
- 3教科（マーケティング・AI演習・リテラシー）は別々ではなく、この目的でつながる【教員】

## 設計の原則（利用者の発言）

- **一本線**: 最上位の思想から最下流（各回の授業・評価）まで線でつながっていること。未定は未定、断絶は断絶と書く
- **逆算**: 何のツールを使い、どんなビジネスシーンで役に立つのかから逆算する
- **必要だから使う**: ツールの使い方を教える授業にしない。仕事を成立させるために必要だから使う
- **本物志向**: 実際に使える・実際に役立つものを作る（「学校で実際に使う」は案の一つに格下げ。本物志向そのものは残る）
- **スマホ完結**: スマホだけで作れる・使えること。レベルは高すぎないこと
- **Google のツールで完結**: Forms・Sheets・YouTube・Gmail など Google の道具だけで一連の仕事が成り立つ（例: Web講演会の構想）
- **Office 系の実務操作**も身につける（表計算・文書・フォーム・集計）
- **科目どうしで被らない**。各科目のテーマと整合する
- **3教科の役割**: マーケティング＝商談力、AI演習＝実装力、リテラシー＝運用力。前工程の内容が後工程の採点項目になる（企画を形にしているか／形にしたものを担保しているか）
- 運用には**コスト**・法的な確認・利用規約も入る
- プレゼンばかりにしない。形式は科目ごとに変わってよい（話す・作る・書く）
- 月に合わせて区切らない
- 学校指定教科書は参考書。中心教材は Gemini Notebook【教員】
- 日本語がわからない時もAIで自分で解決する。できない言い訳は受け付けない【教員】
- 要求水準は高い。一般論・どこにでもある案は不可。具体的に、解説は不要

## 採点の思想（利用者の発言）

- 最低でも49点は取らせたい。そこまではハードルが低い【曖昧】（100点中か、評価物80点中かは確認中）
- 落ちこぼれでも、再提出を手取り足取り行えば最低点は取れる
- それ以上は頑張った分だけ評価に反映される。点数が上がるごとに難易度が跳ね上がる＝一段ずつ高くなる階段

## 評価の枠（確定）

- 評価物80点（1教科5個）＋小テスト20点（授業中に完結する態度点。欠席は0点）
- 期末試験は必須ではない
