## 特に重要な事実（要約）
- 令和8年4月1日以降の入学者から、専門課程はすべて単位制になる。1単位は45時間の学修が標準。講義・演習は15〜30時間、実験・実習・実技は30〜45時間の授業で1単位。ただし文部科学省は、旧基準（年間800単位時間）と同水準以上の教育課程を求めている（01 §2）。
- 専門学校がシラバスを作成・公表する直接の根拠は、修学支援新制度の機関要件「厳格かつ適正な成績管理」である。公表は一般に向けて行う必要があり、学内限定では要件を満たさない（01 §4）。
- 専修学校設置基準には、大学設置基準第25条の2（授業計画・成績評価基準の明示）に相当する条文が見当たらなかった（01 §2-2）。
