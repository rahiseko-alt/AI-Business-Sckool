## 6章末 COLUMN ニュースにもなった「サプライ・チェーン」（p.134【曖昧】）

- 要点:
  - 「サプライ・チェーン」はコロナ禍初期のマスク不足や世界的な半導体不足のニュースで製品流通網の意味でよく使われたが、正しくは原材料の調達から消費者に商品・サービスが届くまでの長い連鎖を指す。
  - 「サプライ・チェーン・マネジメント（SCM）」では消費者をチェーンのゴールであると同時に出発点とも考える。垂直的マーケティング・システム（VMS）が消費者を単にゴールと見るのとの大きな違い。
  - VMSでは消費者は枠の外で商品を受け取るだけだが、SCMでは消費者がチェーンの枠の中に入り、双方向の矢印（チャネル）になる。
  - 例: 消費者がCPUやメモリなどの仕様を指定し、メーカーが組み立てて届ける BTO（Built To Order）。デル（Dell）のBTOはSCMの成功例とされる。
- 用語: サプライ・チェーン、SCM、VMS（垂直的マーケティング・システム）、BTO、デル
- マーカー: なし

## 7章 効果的に伝える「コミュニケーション戦略」（扉 p.135【曖昧】）

### 57 どのコミュニケーション方法を選べばいいの？（p.136〜137）

- 小見出し: 「コミュニケーションはむずかしくなる一方」／「人的・非人的の『コミュニケーション・チャネル』がある」
- 要点:
  - 製品・価格・流通ができても消費者に知られなければ意味がないので、売り手からコミュニケーションが必要。マーケティング・ミックス（18ページ参照）の第4戦略「プロモーション」はコミュニケーションのこと。本章は「4つのC」にならって「コミュニケーション」と呼ぶ（「4つのP」派はプロモーションと読み替えてよい）。
  - 消費者の多様化と情報の氾濫で、コミュニケーションのむずかしさは増す一方。
  - マーケティングでは市場に届ける経路として3つのチャネルを考える: 流通チャネル（124ページ参照）、販売チャネル（小売業者・電子商取引など）、コミュニケーション・チャネル。
  - コミュニケーション・チャネルは「人的（パーソナル）」と「非人的（ノンパーソナル）」に分けられる。
- 用語: プロモーション、4つのC／4つのP、流通チャネル、販売チャネル、コミュニケーション・チャネル、人的（パーソナル）／非人的（ノンパーソナル）
- 図「『コミュニケーション・チャネル』とは？」: ツリー図。チャネル →（コミュニケーション・チャネル／流通チャネル／販売チャネル）。コミュニケーション・チャネル →（人的コミュニケーション・チャネル: 対面、電話、メール、SNS、口コミなど／非人的コミュニケーション・チャネル: メディア（テレビ、新聞、雑誌等）、販売促進、イベント、PR、ウェブなど）。図の結論「『コミュニケーション・チャネル』には人的（パーソナル）と非人的（ノンパーソナル）がある」。
- マーカー: なし

### 58 コミュニケーションは「ミックス」で考える（p.138〜139）

- 小見出し: 「コミュニケーション方法は広告だけじゃない」／「4つの方法プラスアルファをミックスする」
- 要点:
  - マーケティングのコミュニケーションというとまず広告が浮かぶが、方法はほかにもあり、商品によっては別の方法が適することもある。
  - 基本の4つ: 広告（テレビ・新聞・ラジオ・雑誌・インターネットなど「広告媒体」）、販売促進（店頭POP広告、展示会、イベントなどさまざまな活動の総称）、PR（プレス・リリース、広報誌発行などの広報活動）、人的販売（対面の双方向コミュニケーション）。
  - 日本ではこれに「口コミ」を加えることも多く、「ダイレクト・マーケティング」（148ページ参照）もあげられる。
  - これらを組み合わせてコミュニケーションを行なうことを「コミュニケーション・ミックス」という。
- 用語: 広告、広告媒体、販売促進、PR、人的販売、口コミ、ダイレクト・マーケティング、コミュニケーション・ミックス
- 図「『コミュニケーション・ミックス』とは？」: 中心「コミュニケーション」を4分割の円（広告／PR／人的販売／販売促進）が囲み、外側に扇形で「口コミ」「ダイレクト・マーケティング」が付く。結論「いろいろな方法を組み合わせるのが『コミュニケーション・ミックス』」。
- マーカー: なし

### 59 「広告媒体」はどうミックスすればよいか（p.140〜141）

- 小見出し: 「広告媒体を組み合わせる『メディア・ミックス』」／「媒体の特徴を活かした組み合わせが大切」
- 要点:
  - 広告の第1の特徴は、スポンサー名を付けて有料で発信すること（「有料」の理由は146ページ参照）。
  - 広告を載せる媒体（広告媒体・メディア）には特徴があり、テレビは広域に伝わるがコスト高、ラジオは比較的安い。特徴を考えて組み合わせるのが「メディア・ミックス」（マーケティング・ミックス＞コミュニケーション・ミックス＞メディア・ミックスという入れ子）。
  - 広告媒体は、マスコミ4媒体のほか、インターネット、販売促進の一環のSP広告（142ページ参照）、衛星メディア関連（マスコミ4媒体に含まれない放送など）と意外に多い。
  - 例: テレビはインパクトと視聴者数は抜群だがコスト高・情報量少 → 安いラジオ、情報量の多い新聞と組み合わせる。新聞は読者数で雑誌を上回るが、雑誌はライフスタイル（72ページ参照）で読者のセグメントができる。
- 用語: 広告媒体、メディア、メディア・ミックス、マスコミ4媒体、インターネット広告、SP広告、衛星メディア関連
- 図「『メディア・ミックス』とは？」: 中心「広告」の円を4区分。マスコミ4媒体（テレビ、新聞、雑誌、ラジオ）／インターネット広告（バナー、リスティング、アフィリエイト、メール）／SP広告（折り込み、交通広告、DM、POP、屋外広告）／衛星メディア関連（衛星放送、CATV、文字放送）。結論「広告媒体にはそれぞれ特徴があるから特徴を活かした『メディア・ミックス』が大切」。
- マーカー: なし

### 60 「販売促進」はとにかくいろいろ（p.142〜143）

- 小見出し: 「『SP広告』と『セールス・プロモーション活動』がある」／「SP広告はどんなものがあるか」
- 要点:
  - 販売促進は英語で「セールス・プロモーション」、略して「販促」。広告との大きな違いは「インセンティブ（報奨）」の働きがあること（オマケを付けて買ってもらうのも立派なインセンティブ）。
  - 販売促進は大きく「セールス・プロモーション広告（SP広告）」と「セールス・プロモーション活動」に分かれる。本項はSP広告、次項で活動を扱う。
  - SP広告の例: POP広告（ポイント・オブ・パーチェス＝購買時点広告）、ダイレクト・メール（DM）、ダイレクト・ハンド（DH）、折り込み広告（折り込みチラシ）、街頭配布、店頭配布、戸別配布、屋外広告、特定施設内広告、フリーペーパー、フリーマガジン、交通広告（車体広告・電車の車内広告・駅広告・駅貼り・タクシー広告）。
- 用語: セールス・プロモーション、販促、インセンティブ（報奨）、SP広告、セールス・プロモーション活動、POP広告、DM、DH、折り込み広告、交通広告、屋外広告、特定施設内広告
- 図「『SP広告』もいろいろ」: 中心「SP広告」から放射状。POP広告、ダイレクト・メール、ダイレクト・ハンド、折り込み広告、街頭配布、店頭配布、戸別配布、屋外広告（広告板、広告塔、はり紙、広告旗、宣伝車、立て看板、電柱広告）、特定施設内広告、フリーペーパー、フリーマガジン、交通広告（車体広告、電車広告〔中吊り、窓上、ドア横、吊り革〕、バス広告、駅広告〔駅貼り〕、タクシー広告）。
- マーカー: なし

### 61 「ノベルティ」も「リベート」も販促のうち（p.144〜145）※画像がピンボケ、大部分【曖昧】

- 小見出し: 「『消費者向け』『流通向け』『社内向け』がある」【曖昧】／「『インセンティブ』とはどういうもの？」
- 要点（読み取れた範囲）:
  - セールス・プロモーション活動は大きく「消費者向けプロモーション」「流通業者向けプロモーション」「社内向けプロモーション」に分けられる【曖昧】。
  - 消費者向け: 店頭ディスプレー（デモンストレーション）、試供品・見本（サンプル）、割引券（クーポン）、引換券（バウチャー）、現金の払い戻し（キャッシュ・バック）、スタンプ（スタンプ・サービス）、展示会（セールスショー）、イベントへの資金提供（イベント・スポンサーシップ）など【曖昧】。
  - オマケなどを付けて買う気にさせるのが「インセンティブ」。消費者向けでは景品を付ける「プレミアム」、記念品程度を付ける「ノベルティ」、競技会を開く「コンテスト」が代表的【曖昧】。

- 用語: プレミアム、ノベルティ、コンテスト、リベート、ディーラー・ヘルプス、トレードショー、クーポン、バウチャー、キャッシュ・バック、セールス・インセンティブ【いずれも曖昧】

### 62 知っておきたい「PR」の本当の意味（p.146〜147）

- 小見出し: 「広告（AD）とPRの違いとは？」／「プレス・リリース、取材対応などの報道対策も」
- 要点:
  - PRはパブリック・リレーションズの略で、日本語では「広報」などと訳される。広告はアドバタイズメント（AD）。
  - PR活動の1つ「パブリシティ」は、製品情報などをマスコミに提供して記事として取り上げてもらうもの。媒体料金を払わない＝無料の広告のようなもの。
  - 広告の手法として情報を記事やニュースの形で流すこともあるが、料金を払うのでパブリシティではなく「ペイド・パブ（リシティ）」という。
  - PRは企業がパブリック（公衆）と良好な関係を築く活動で、「ピーアール」は単なる宣伝ではない。報道対策（プレス・リリース配信、取材対応、記者会見＝プレス・カンファレンス）が大きな部分を占める。広報誌発行や社会貢献活動もPR。
  - PR活動は広告に比べ消費者の信頼を得やすく、記事の方が広告より信頼され、買わされる警戒心も起きにくい。
- 用語: PR（パブリック・リレーションズ）、広報、AD（アドバタイズメント）、パブリシティ、ペイド・パブ、報道対策、プレス・リリース、記者会見（プレス・カンファレンス）
- 図「PR＝『パブリック・リレーションズ』のこと」: PR → パブリシティ（製品パブリシティ: 話題性のある新製品情報などを提供／ニュース・パブリシティ: 決算情報など企業の動向を知らせる／サービス・パブリシティ: イベント等一般にも興味深い情報を提供）、報道対策（プレス・リリース、取材対応、記者会見など）、そのほか（広報誌の発行、社会貢献活動……）。結論「無料のパブリシティなど、広告より消費者の信頼を得やすいPRを活用しない手はない」。
- マーカー: なし

### 63 「ダイレクト・マーケティング」とは？（p.148〜149）

- 小見出し: 「間に入れず『ダイレクト』にコミュニケーション」／「その場で注文も受けられる」
- 要点:
  - コミュニケーション・ミックス（138ページ）の1つ。消費者個人に向けて直接働きかけるコミュニケーションで、間に仲介業者が入らない。
  - コトラーはダイレクト・マーケティングの特徴を3つあげる: ①カスタマイズ（個々人に合わせて調整）②即時性（その場で質問に応え注文を受けられる）③双方向性（反応に応じて修正できる）。
  - ダイレクト・メールは従来からのSP広告の1つ（142ページ）、テレ・マーケティングは人的販売（150ページ）に近い。注目されるのは、先進国で人的販売のコストが高くなっているため。
  - 反応＝注文がその場でわかるのが大きなメリット。広告・販売促進・PRではそうはいかない。
- 用語: ダイレクト・マーケティング、コトラー、カスタマイズ／即時性／双方向性、テレ・マーケティング
- 図「主な『ダイレクト・マーケティング』の方法」: 4つの楕円。ダイレクト・メール（パンフレットなどを送って注文してもらう）、テレ・マーケティング（電話を使ってコールセンターで注文や問い合わせに答える）、カタログ・マーケティング（カタログを送って注文してもらう）、インターネット・マーケティング（ウェブやメールで注文などに応える）。結論「他のコミュニケーション方法と違って、その場で注文や、ときには問い合わせにも答えられる」。
- マーカー: なし

### 64 マーケティングのシメは「人的販売」（p.150〜151）

- 小見出し: 「『人的販売』はどこに位置するか」／「最も古くて新しいコミュニケーション」
- 要点:
  - 人的販売とは営業担当者・販売員など「人」による直接的な販売活動＝コミュニケーションで、コミュニケーション戦略のシメ。
  - AIDMAモデル（154ページ）の注目・興味・欲求・記憶では広告やPRが力を発揮し、行動の段階では販売促進と人的販売が力を発揮する。迷っている消費者の「背中を押す」のが人的販売。
  - プッシュ戦略・プル戦略（126ページ）で見ると、プル戦略は主に広告・PR・販売促進、プッシュ戦略は人的販売なしには成り立たない。
  - 人的販売は、ダイレクト・マーケティングの3特徴を満たす最古の形。マス・マーケティングから出発した最新の考え方（74ページ）が最古のコミュニケーションにつながっている。「セリングは不要になる」という意見もあったが（12ページ）、人的販売はますます重要に。
- 用語: 人的販売、AIDMAモデル、プッシュ戦略、プル戦略、セリング
- 図「『人的販売』はいつの時代もシメに位置する」: 左にAIDMA（Attention 注目、Interest 興味、Desire 欲求、Memory 記憶／Action 行動）、右に扇形の広告→PR→販売促進→人的販売（人的販売のみ濃色）。注目〜記憶は広告・PR・販売促進に対応し「プル戦略」、行動は販売促進・人的販売に対応し「プッシュ戦略」。
- マーカー: なし

### 65 結局、重要なコミュニケーションはどれ？（p.152〜153）

- 小見出し: 「『統合型マーケティング・コミュニケーション』とは」／「コミュニケーションがバラバラではダメ」
- 要点:
  - どれか1つをやれば大丈夫という方法はなく、各方法の特徴を活かした組み合わせ＝コミュニケーション・ミックス（138ページ）が大切。
  - これをあらわす用語が「統合型マーケティング・コミュニケーション（IMC）」。米ノースウェスタン大学のドン・シュルツ教授らが提唱。広告・販売促進・PR・人的販売などを統合し最大限の効果を実現する考え方。
  - 例: 新製品のパブリシティに続いてテレビCM、CMで「詳しくはWebで」と誘導、申し込むとサンプル送付、サンプルから口コミ、店頭で販売員が説明して購入。
  - インターネット普及でコミュニケーションの種類も情報量もケタ違いに多くなり、バラバラではダメ。IMCはますます重視されている。
- 用語: IMC（インテグレーテッド・マーケティング・コミュニケーション）、ドン・シュルツ、ノースウェスタン大学
- 図「統合できれば効率も上がる」: 中心「統合型マーケティング・コミュニケーション（IMC）」の周囲を PR→広告→ダイレクト・マーケティング→口コミ→販売促進→人的販売→PR と矢印が循環。結論「それぞれのコミュニケーション活動をいま以上に統合して最大限の効果をあげる」。
- マーカー: なし

### COLUMN 消費者はAIDMAで買う？AISASで買う？（p.154）

- 要点:

## 8章 デジタル・マーケティングはAIマーケティングへ（扉 p.155【曖昧】）

### 66 デジタル・マーケティングはどこが違うの？（p.156〜157）

- 小見出し: 「デジタル・マーケティングの4つの『デジタル』」／「デジタル・マーケティングの5つの特長」
- 要点:
  - デジタル・マーケティングとは、ウェブサイトなどのデジタル・メディアや、ITなどのデジタル・テクノロジー（技術）を活用するマーケティングの総称。スマホなどのデジタル・デバイス（機器）を使い、購買履歴などのデジタル・データを扱う（4つの「デジタル」）。
  - 5つの特長: ①効果の測定が簡単で正確（広告費と売上を数値でつかめる）②一人ひとりを対象にできる（検索したユーザーに近くの店の広告を出すなど）③低コストで始められる（無料サービス、少額からのウェブ広告）④すべてがスピーディ ⑤マーケティングの対象が広い（日本語の通販サイトなら世界中の日本語を理解する人が対象）。
- 用語: デジタル・メディア／テクノロジー／デバイス／データ
- 図「デジタル・マーケティングにはこんな特長がある」: 左「デジタルでないマーケティング」から右「デジタル・マーケティング」へ5本の矢印（①〜⑤の特長）。結論「このような特長があるためデジタル・マーケティングは小さな会社でも始められる」。
- マーカー: なし

### 67 ウェブだけじゃないデジタル・マーケティング（p.158〜159）

- 小見出し: 「SNSマーケティングやアプリ・マーケティングも」／「コンテンツ・マーケティングからバズ・マーケティングまで」
- 要点:
  - 長らく「ウェブ・マーケティング」が使われたが、現在はデジタル・マーケティングの一部という位置づけ。メール・マーケティング、近年重視のSNSマーケティング、スマホのアプリ・マーケティング、5G普及で確立した動画マーケティングも。
  - 手法で見ると、発信する情報の中身で勝負する「コンテンツ・マーケティング」、ユーザーに見つけてもらい顧客化・リピーター化まで目指す「インバウンド・マーケティング」（内側に向かう）、影響力のある人に紹介してもらう「インフルエンサー・マーケティング」、AIを活用する「AIマーケティング」（168ページ）、とにかく話題にさせる「バズ・マーケティング」（「バズる」を一般化させた）。
- 用語: ウェブ／メール／SNS／アプリ／動画マーケティング、コンテンツ・マーケティング、インバウンド・マーケティング、インフルエンサー、AIマーケティング、バズ・マーケティング
- 図「ウェブだけじゃないデジタル・マーケティングのいろいろ」: 2列の表。「メディアで見ると」（ウェブ、メール、SNS、アプリ、動画 など）／「手法で見ると」（コンテンツ、インバウンド、インフルエンサー、AI、バズ など）。結論「デジタル・マーケティングはさまざまなメディア、手法を駆使する」。

### 68 「SEM」はデジタル・マーケティングの基本（p.160〜161）

- 小見出し: 「SEM（サーチ・エンジン・マーケティング）とは」／「リスティング広告は広告料金が発生する検索」／「広告でない検索結果は『自然検索』」
- 要点:
  - 多くの人がGoogleなどの検索エンジン経由でサイトを訪れるので、検索エンジン対策＝SEM（サーチ・エンジン・マーケティング）が欠かせない。
  - SEMは「SEO（検索エンジン最適化）」と「検索連動型広告」に分けられる。SEOは検索結果の上位に表示されるための対策。良質なコンテンツ提供を続けるコンテンツ・マーケティングも上位表示を狙う。
  - 検索連動型広告＝「リスティング広告」は検索結果の上に「広告」と明記される。キーワードを指定し、クリックされると料金が発生。「ペイド・リスティング」とも。
  - 広告でない検索結果は「自然検索」（ナチュラル・サーチ、オーガニック・サーチ）で、いくら上位でも料金は発生しない。AI搭載の検索エンジン登場でSEMは大きく変わりつつある（168ページ）。
- 用語: SEM、SEO、検索連動型広告、リスティング広告、ペイド・リスティング、自然検索、ナチュラル・サーチ、オーガニック・サーチ
- 図「SEMには自然検索の対策と広告がある」: SEM（サーチ・エンジン・マーケティング）→ SEO（検索エンジン最適化）→ 自然検索／リスティング広告（検索連動型広告）→ ペイド・リスティング。結論「検索エンジン対策としてはSEOによって『自然検索』の上位に表示されることが重要」。
- マーカー: なし

### 69 「アクセス解析」でユーザーの行動を分析する（p.162〜163）

- 小見出し: 「アクセス解析は成約の数を増やす」／「アクセス解析はサイトの改善に役立つ」
- 要点:
  - SEMは訪問者を増やすのが目的だが、サイトの目的（購入、会員登録、資料請求など）につなげる必要がある。サイトの目的を「コンバージョン」（日本語で「成約」）という。
  - 成約を増やす対策の代表が「アクセス解析」。訪問者の特性やサイト内の行動を分析し、数やパーセンテージで効果を正確にあらわす。課題の発見と改善に役立ち、Googleアナリティクスなどの無料の「アクセス解析ツール」が一般的。
  - 目的は成約の数や率を高めること。よく見られるページや、SNS経由の訪問者がスマホ向けページで成約しやすいことがわかれば改善策を立てられる。
- 用語: コンバージョン（成約）、アクセス解析、Googleアナリティクス、アクセス解析ツール、PV（ページビュー）、CV率、直帰率、離脱率
- 図「アクセス解析では何を分析するのか」: 検索エンジン・広告・SNS → 最初に見るページ（ここだけ見て帰った人＝直帰率）→ ページA・B・C（何回見られたか＝PV数、このページで帰った人＝離脱率）→ 成約のページ（成約した人＝CV〈コンバージョン〉率）。結論「このようなデータを収集し、分析して成約を増やすのがアクセス解析」。
- マーカー: なし

### 70 ウェブだけじゃない「デジタル広告」のいろいろ（p.164〜165）

- 小見出し: 「デジタルには多様な広告がある」／「デジタル広告に欠かせない『アドテクノロジー』」
- 要点:
  - 主なメディアだけで「ウェブ」「メール」「SNS」「アプリ」の4種類。表示形式で「テキスト」「バナー」「リスティング」「動画」の分類も可能。
  - 手法の面では、インフルエンサーとタイアップする「インフルエンサー広告」も。広告であることを隠すと「ステルス・マーケティング（ステマ）」となり、現在は景品表示法違反として規制対象。
  - 課金方式: 成果があがったときに課金される「アフィリエイト広告」（成果報酬課金型）、クリック課金型、インプレッション（表示）課金型など。
  - 配信方式: 一度訪問したサイトの広告が追いかけて表示される「リターゲティング広告」、閲覧・行動・購買履歴をもとにする「行動ターゲティング広告」、アドサーバー／アドネットワーク経由の「アドネットワーク広告」。これらの技術の総称が「アドテクノロジー（アドテク）」。
- 用語: デジタル広告、インフルエンサー広告、ステルス・マーケティング（ステマ）、景品表示法、アフィリエイト広告、成果報酬課金型、クリック課金型、インプレッション課金型、リターゲティング広告、行動ターゲティング広告、アドサーバー、アドネットワーク、アドテクノロジー
- 図「デジタル広告にはいろいろな分類方法がある」: 4ブロックを「＋」で連結。メディア（ウェブ広告、メール広告、SNS広告、アプリ広告）＋表示形式（テキスト広告、バナー広告、リスティング広告、動画広告）＋課金方式（アフィリエイト広告など）＋配信方式（リターゲティング広告など）。結論「ひとつの広告でもメディアはウェブ、形式はバナー、課金はアフィリエイトなどとなる」。
- マーカー: なし

### 71 ウェブ・マーケティングから「SNSマーケティング」へ（p.166〜167）

- 小見出し: 「広がるSNSの利用率、情報収集もSNSで」／「SNSではユーザーとよい関係を築く」
- 要点:
  - SNSはウェブサイトへの流入経路としても重要で、SNS自体のマーケティングも重要性を増す。総務省調査では2024年の13歳〜19歳、20代、30代のSNS利用率はすべて90％超、40代以上も急伸、全世代平均でも80％超（令和6年通信利用動向調査）。
  - 若い世代では検索エンジンより先にSNSで情報収集するのが主流になりつつあり、ファッションやグルメでは既に検索エンジンを超えているというデータもある。
  - 主なSNSはテキスト・画像・動画など特徴が違うので、それぞれに合わせたマーケティングが必要。共通施策はアカウントの運用とSNS広告の出稿。LINEの「公式アカウント（旧LINE@）」、X（旧Twitter）の「プロモアカウント（フォロワー獲得広告）」など。
  - ポジティブなイメージは口コミ・カスタマー・レビュー、イメージアップ、売上増加につながる一方、ネガティブなイメージが拡散すると炎上もありうる。ユーザーとよい関係を築くことが最重要。
- 用語: SNSマーケティング、通信利用動向調査（総務省）、アカウントの運用、SNS広告、公式アカウント、プロモアカウント、炎上
- 図「SNSマーケティングの主な対策は2つ」: 楕円内に Facebook、Instagram、LINE、TikTok、X（旧Twitter）、YouTube。そこへ「アカウントの運用」と「SNS広告の出稿」の2つの矢印。結論「ユーザーとよい関係を築くことが重要なのでコンバージョンはウェブサイトでという手も」。
- マーカー: なし

### 72 なぜ「AIマーケティング」が重要なのか（p.168〜169）

- 小見出し: 「AIの活用により業務効率化と効果最大化が可能」／「従来のマーケティング施策ではAIの影響が避けられない」
- 要点:
  - AIマーケティングとは、AIの技術を活用して、マーケティング活動の全体または部分的に最適化・自動化する手法の総称。
  - 重要な理由: 市場調査や分析、商品企画・開発、広告配信など膨大な時間と手間がかかる業務の効率化と、マーケティングの効果最大化が可能になるから。人間のマーケターが不要になるわけではなく、よりクリエイティブで戦略的な業務に集中できる。
  - もうひとつの理由: AI搭載の検索エンジンで「AIによる概要」が自然検索（161ページ）やリスティング広告より上位に表示され、SEO・リスティング広告（160ページ）の効果が薄れる。
  - そこで研究されているのが「AEO（アンサー・エンジン・オプティマイゼーション）」＝「回答エンジン最適化」。AIの回答に自社コンテンツを最適の回答として表示させる。クリックなしで内容が回答として表示される（ゼロクリック検索）のが特長。
- 用語: AIマーケティング、AIによる概要、AEO（回答エンジン最適化）、ゼロクリック検索、SEO
- 図「AEOは従来のSEOとどこが違うか」: 左右比較。SEO（検索エンジン最適化）: 目的は検索エンジンの検索結果上位／クリックされて自社のコンテンツが表示。AEO（回答エンジン最適化）: 目的は自社のコンテンツを回答として表示／クリックなしに表示（ゼロクリック検索）。結論「従来の検索エンジン最適化では検索結果上位に表示されることはできない」。
- マーカー: なし

### 73 AIマーケティングはいつ、何ができるのか（p.170〜171）

- 小見出し: 「データの分析から『パーソナライゼーション』まで」／「コンテンツ生成や24時間顧客対応はAIの得意分野」
- 要点:
  - AIマーケティングの施策は多岐にわたり、マーケティング活動のほとんど全体に及ぶ。
  - 最もAIらしいのはデータ分析や予測。個々の顧客データだけでなく市場全体のトレンド・動向の分析も。そこから戦略立案も可能。個々の顧客に最適化された情報・商品を提供する「パーソナライゼーション」も。
  - コンテンツ生成（テキスト・画像・音声・動画の生成AI）、広告のクリエイティブ自動生成、広告運用の最適化（アドネットワーク〔165ページ〕の広告オークションは入札〜落札が0.1秒以内でAIが最適といえる）。
  - 顧客対応では、テキストや音声で人間と自動で会話できる「AIチャットボット」で365日24時間の問い合わせ対応、FAQの自動生成も可能。
- 用語: データ分析と予測、戦略立案、パーソナライゼーション、生成AI、広告オークション、AIチャットボット、FAQ
- 図「AIマーケティングによる主な施策」: 6項目の表。データ分析と予測（購買履歴・行動履歴を分析し購買行動などを予測）／戦略立案（分析結果から最適な戦略や改善案を提案）／パーソナライゼーション（属性や行動からウェブサイトの表示やメール・広告を最適化）／コンテンツ生成（商品説明、広告コピー、SNS投稿などを生成）／広告運用（入札調整、配信などをリアルタイムで）／顧客対応（AIチャットボットによる24時間問い合わせ対応、FAQの自動生成など）。結論「要するにAIマーケティングではこんなことが自動でできる」。
- マーカー: なし

### 74 「マーケティング・オートメーション」とAIマーケティング（p.172〜173）

- 小見出し: 「マーケティング・オートメーション（MA）とは」／「セールス・フォース・オートメーション（SFA）とは」
- 要点:
  - AI普及以前からあるマーケティング自動化の取り組みが「マーケティング・オートメーション（MA）」。「MAツール」というソフトを導入し、手間のかかるルーティン業務を自動化する。AI搭載でより完全に近い自動化が進む。
  - MAは見込み客の獲得・育成から購買促進までを自動化するしくみ。顧客データの管理・分析、資料請求やサイト訪問など行動の追跡・記録、パーソナライズされたメールの自動配信など。従来はシナリオを人間が設定する必要があるなどの課題があった。
  - MAツールにAIを搭載し、誰に・何を・いつ・どこで発信するかをAIが判断する「AI」をうたうMAツールが多数登場。
  - MAの仕事は、成約可能性の高い顧客＝ホットリードのリストを営業部隊に渡すところまで。その後の営業支援が「セールス・フォース・オートメーション（SFA）」。SFAツールは顧客情報・交渉記録・進捗状況・販促資材・行動予定などを一元管理し営業部隊に提供する。AIで「営業支援の自動化」をより完全に近い形で実現しようとしている。
- 用語: マーケティング・オートメーション（MA）、MAツール、見込み客、ホットリード、セールス・フォース・オートメーション（SFA）、SFAツール
- 図「マーケティングを自動化する」【見出し末尾一部判読不能】: 資料請求・サイト訪問・名刺交換 → MAツール（顧客データの管理・分析、顧客の行動の追跡・記録）→ メール配信（見込み客へ）。結論「顧客データの管理やメール配信はMAツールが自動でやってくれる」。
- マーカー: なし

### COLUMN マーケティングの効果を測るKGIとKPI（p.174）

- 要点:
  - 効果を簡単・正確に測れるデジタル・マーケティングでは、KGIとKPIの設定がよく行なわれる。
  - KGI＝キー・ゴール・インジケーター（重要目標達成指標）。最終的に達成する目標を「次月の成約件数○○件」など数値で具体的に定める。
  - KGIの数字だけでは対策を考えられないため、別にKPI＝キー・パフォーマンス・インジケーター（重要業績評価指標）を定める。例: 新規訪問者が多く成約件数に大きく影響すると思われる検索エンジンからの訪問者数をKPIに設定。
  - 訪問者数が伸びていなければ、SEO強化、急ぐならリスティング広告出稿などの対策が打てる。KGIは最終目標（ゴール）、KPIは最終目標の達成度を測る中間目標。
- 用語: KGI、KPI
- マーカー: なし
