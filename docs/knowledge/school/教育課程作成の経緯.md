## 1. 本教育課程を設計した背景

- 本校の商業実務専門課程は、主に留学生が入学し、日本での就職を目指す教育課程である。
- 学生の多くは卒業後、「技術・人文知識・国際業務（技人国）」の在留資格による就職を目標としている。
- 従来の専門学校のビジネス教育をそのまま留学生に適用すると、以下の課題が生じる。

（1）入学時の日本語能力
- 多くの学生は JLPT N3 程度、一部 N2 レベル、日本語学校修了直後という状態で入学する。
- 専門科目を学ぶには N2 以上が望ましいとされるが、到達していない学生も多い。

（2）ビジネス教育の特性
- 商業実務分野は技術技能ではなく知識中心、座学が多くなりがち、日本語理解への依存度が高い。
- 日本語能力が十分でない場合、授業理解が困難、学習意欲の低下、専門知識の習得が進まない。

（3）日本での就職において最も重要な能力
- 企業の留学生採用で最も重視される要素は ①日本語でのコミュニケーション能力、②日本企業文化への理解、③業務遂行能力。
- **専門知識よりも、日本語で業務を遂行できる能力が前提条件**となっている。

## 2. 日本語学校教育との違い

- 専門学校は日本語学校ではないため、日本語の授業だけを中心にすることや JLPT 対策だけを行うことは本来の専門教育とは言えない。
- 一方で、専門教育と日本語能力向上を同時に実現する教育設計が必要。

## 3. 本校の教育コンセプト

- 教育理念: **「日本語運用統合型商業実務専門課程」**。専門教育の中で日本語運用能力も同時に高める教育モデル。
- 基本的な考え方: 「日本語を教える」ことを目的とするのではなく、**日本語を使ってビジネスを遂行する力を育てる**ことを目標とする。
- 授業、課題、発表、ディスカッション、レポート等の成果物、**すべての教育活動が日本語運用能力とビジネスを遂行する力の向上につながる設計**とする。

## 4. 教育課程の基本構造（原文は「3つの領域」と書きつつ①〜④の4つを列挙）

1. ビジネス基礎（経営・マーケティング・会計など）— ビジネスの基本構造を理解する／技人国在留資格の「人文知識分野」に接続する
2. 実務技能科目（IT・プレゼンテーション・ビジネス文書・AI 活用など）— 就職後すぐに使える実務能力の育成
3. 就職・キャリア系科目（キャリア形成演習、就職・キャリアガイダンス、など）— 入学時から就職を意識した学習／自己分析とポートフォリオ形成
4. 国際・語学系科目（国際コミュニケーション、実務系日本語科目、など）— 国際業務への接続／多文化環境での業務遂行能力

## 5. 在留資格（技人国）との関係

- 卒業後に技人国で就職する場合、履修した科目と業務内容の関連性が審査される。
- そのため「マーケティング」「ホスピタリティ」「国際ビジネス」「ビジネス法務」「データ活用」などの科目を配置し、人文知識・国際業務分野との関連性を明確にしている。

## 6. 学習の入口と出口

| 入学時（入口） | 卒業時（出口）の目標 |
| --- | --- |
| 日本語能力：N3 程度 | 日本語で業務を遂行できる |
| 日本企業文化の理解：限定的 | 日本企業文化を理解している |
| ビジネス知識：ほぼなし | ビジネス課題を分析できる |
| | データを使って説明できる |
| | 異文化環境で協働できる |
| | AI などのツールを業務に活用できる |

## 7. 本課程の特徴

1. **すべての授業が日本語能力向上につながる** — 専門科目の学習を通じて、日本語運用能力を高める。
2. 就職を前提としたカリキュラム — 入学時から就職活動を意識した学習を行う。
3. 実践中心の授業 — PBL、ディスカッション、プレゼンテーションを中心とする。
4. AI 時代のビジネス教育 — AI ツールの活用を前提とした実務教育を行う。

## 8. 教職員の皆様へのお願い

- 「知識を教える授業」ではなく、**学生が日本語で考え、説明し、議論する授業**が重要。発話、討論、発表などのアウトプット活動を積極的に取り入れてほしい。
- そのために、1つの科目を基本的には**通年単位**で、時間をかけて学ぶ設計となっている。

## 9. まとめ

- 留学生の現状と日本企業のニーズを踏まえた「日本語運用統合型商業実務専門課程」として設計。
- 専門知識の習得と日本語能力の向上を同時に実現し、日本社会や国際社会で活躍できる人材を目標とする。
