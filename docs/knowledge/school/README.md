## 学校資料と教員方針の食い違い

各項目で、学校側（school）と教員側（teacher）の出典を併記する。判断や解決はここではしない。

1. **日本語能力を育てるか、AI能力に集中するか**
   - 学校: 「すべての教育活動が日本語運用能力とビジネスを遂行する力の向上につながる設計」「すべての授業が日本語能力向上につながる」「学生が日本語で考え、説明し、議論する授業」（[教育課程作成の経緯.md](教育課程作成の経緯.md) §3・§7(1)・§8）
   - 教員: 「この授業では、日本語能力を育てることではなく、AI能力を磨くことに重点を置きます」「日本語が分からない場合は、AIを使って母国語で理解を補助」（[../teacher/小齊平授業方針_AIビジネス能力を身につける.md](../teacher/小齊平授業方針_AIビジネス能力を身につける.md) 06・17）

2. **主教材: 学校指定教科書か、NotebookLM／ChatGPTか**
   - 学校: マーケティング『図解でわかる マーケティングの基本としくみ ＜改訂2版＞』、AI演習『合格対策生成AIパスポート テキスト&演習問題 第２版』、ビジネス情報リテラシー『留学生のためのITリテラシー』を指定（[時間割_国際ビジネスAI科_1年次前期.md](時間割_国際ビジネスAI科_1年次前期.md)、[科目と教科書_1年次.md](科目と教科書_1年次.md)）。科目表はAI演習Ⅰを『生成AIパスポート』合格対策と定義（[科目表.md](科目表.md)）
   - 教員: 「Gemini NotebookLMを3教科共通の教科書」「学校指定の教科書は、補足の参考書」（授業方針 07）。統合シラバス案ではAI基礎は「無料版ChatGPTを中心」（[../teacher/4科目統合型シラバス.md](../teacher/4科目統合型シラバス.md) §2）
   - 参考: 利用者は2026-09-28に「学校指定教科書は参考書として扱う」と決定（`../history/README.md`）。教員方針側と同じ向き
   - 補足: 教員作成の練習問題・期末試験は教科書ページ（P4〜P110）を参照して作られており、実際の出題は教科書に沿っている（[../teacher/生成AI練習問題9.7小齊平作成.md](../teacher/生成AI練習問題9.7小齊平作成.md)）

3. **AI演習の科目名（（実践）／（理論）／Ⅰ・Ⅱ／AI基礎）**
   - 学校内でも不一致: 科目表「AI演習 Ⅰ／Ⅱ」（区別なし）／時間割「AI演習（実践）」火8:30、生成AIパスポート教科書／科目と教科書「AI演習（理論）Ⅰ」火3・4（生成AIパスポート教科書）と「AI演習 Ⅰ（実践）」木3・4（教材なし）／通知表編集用「AI演習（実践）Ⅰ」形態「講義」、見本「AI演習（実践）」形態「演習」／期末試験「AI演習（実践１）」
   - 教員: 「AI演習」（授業方針 01）、統合シラバス「AI基礎」（水曜）、Gemini Notebook手順書の例「AI基礎｜第1回」

4. **リテラシーの科目名**
   - 学校: 時間割・科目と教科書「ビジネス情報リテラシー」（後期は「ビジネスIT」に変わる、[科目と教科書_1年次.md](科目と教科書_1年次.md)）。科目表にはリテラシー科目が無く、IT系は「ITスキル Ⅰ（ITパスポート対策）／Ⅱ」（[科目表.md](科目表.md)）。通知表編集用は後期も「ビジネス情報リテラシー」
   - 教員: 「リテラシー」（授業方針 01・18）、統合シラバス「ITリテラシー」

5. **マーケティングの年次と名称**
   - 学校: 科目表は「マーケッティング」共通・**2年次**（[科目表.md](科目表.md)）。時間割・科目と教科書は**1年次前期**「マーケティング（Ⅰ）」月曜
   - 教員: 「マーケティング」を1年の担当3教科の1つとして扱う（授業方針 01）

6. **授業の曜日**
   - 学校: 月 マーケティング／火 AI演習（実践）／金 ビジネス情報リテラシー（[時間割_国際ビジネスAI科_1年次前期.md](時間割_国際ビジネスAI科_1年次前期.md)）。科目と教科書ではAI演習（理論）火3・4、AI演習（実践）木3・4
   - 教員: 統合シラバス案は 月 マーケティング／**水 AI基礎**／金 ITリテラシー（[../teacher/4科目統合型シラバス.md](../teacher/4科目統合型シラバス.md) §2）。水曜は学校時間割ではビジネス演習（理論）・就職指導

7. **成績評価の配分**
   - 学校: 学習成果60〜100点（1項目以上）、学習姿勢は合計40点まで・1項目10点または20点、項目は最大5つほど。例に期末試験・中間試験（[成績と評価方法について.md](成績と評価方法について.md) §2・§3）
   - 教員: 統合シラバス案は 25%／25%／20%／15%／15% の5項目で、学習成果・学習姿勢の区分が無く、15点の項目がある（[../teacher/4科目統合型シラバス.md](../teacher/4科目統合型シラバス.md) §8）。授業方針はスマホ忘れ・充電切れを「減点」とするが、どの評価項目で扱うか未記載（授業方針 08・10）
   - 参考: 利用者の決定は「中間30、期末30、課題提出30、態度10」で、2026-09-28に「課題は小テストなので学習姿勢に数える」と改めた（`../history/README.md`）。この場合、学習姿勢は合計40で上限内だが、課題提出30は学校規程の「1項目は10点または20点」を超える【曖昧: 要確認】。統合シラバス案の配分はこの決定とも異なる

8. **科目の構成（3教科か4科目か）**
   - 学校: キャリア形成演習は独立科目（時間割 水12:10、通知表「キャリア形成演習Ⅰ／Ⅱ」、[通知表_編集用.md](通知表_編集用.md)）

   - 参考: 2026-09-28、利用者は「キャリア形成演習は対象外（担当から外れた）」と決定（`../history/README.md`）

9. **通年設計と20週サイクル**（食い違いの可能性）
   - 学校: 「1つの科目を基本的には通年単位で、時間をかけて学ぶ設計」（[教育課程作成の経緯.md](教育課程作成の経緯.md) §8）。科目と教科書・通知表はⅠ（前期）／Ⅱ（後期）に分割
   - 教員: 統合シラバス案は20週間・5サイクルで完結する設計。前期・後期のどちらに当たるかの記載なし【曖昧】

10. **スマートフォンの扱い**（方向は一致、程度が異なる）
    - 学校: 「During class, use your phone only when the teacher instructs you.」（[オリエンテーション資料_English_v4.md](オリエンテーション資料_English_v4.md) スライド9）
