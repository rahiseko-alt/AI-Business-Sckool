### 8 マーケティング戦略は経営戦略とともに（p.28〜29）

小見出し: マーケティングが経営戦略と違ってはいけません／あなたのところの「戦略事業単位」は何ですか？

- 要点:
  - 会社には会社としての経営戦略があり、大企業なら事業部ごとの戦略もある。その下にあるのが製品ごとの戦略で、マーケティングの戦略は通常この製品レベルで立てる。製品レベルにはほかに人事の戦略・財務の戦略もある。
  - マーケティング戦略は全社の経営戦略の一部。本来マーケティングは全社経営戦略から始まるので、会社・事業部の戦略と一貫性がなくてはならない。
  - 例1: エブリデー・ロー・プライスを打ち出すスーパーが、高級ワインの大きなコーナーを設けたら、ロープライスを期待した客に受け入れられない。
  - 例2: 高級志向の百貨店のお惣菜売り場が質を落とした290円弁当を出せば、企業イメージを傷つけるおそれがある。エブリデー・ロー・プライスも価格戦略の1つ（118ページ参照）。
  - 製品ごとのマーケティング戦略を立てる単位を「戦略事業単位（SBU）」という。大企業では事業部の下に位置する。中小企業では事業部そのもの、小さな会社では会社自体が SBU になることもある。
- 用語: 経営戦略（全社戦略）、事業部戦略、製品戦略、人事戦略、財務戦略、戦略事業単位（SBU＝ストラテジック・ビジネス・ユニット）、エブリデー・ロー・プライス
- 図表「戦略は4つか3つのレベルで立てられている」（p.29）:
  - 縦の流れ: 全社戦略 → 事業部戦略（←「大企業の場合」）→ 戦略事業単位 戦略 → 製品戦略（マーケティング戦略／人事戦略／財務戦略／…）
  - 戦略事業単位には「3つの特徴がある」:
    - ① 会社の他の部門から独立して計画を立案できる
    - ② 事業単位として、独自の競争相手がいる
    - ③ 計画と成果に責任を持ち、利益に影響する要因をコントロールできるマネジャーがいる

### 9「バリューチェーン」で競争優位のありかを探す（p.30〜31）

小見出し: 会社には「主活動」と「支援活動」がある／どの活動に競争優位があるか、明らかにする

- 要点:
  - 戦略を立てるには、まず自社のどこに強みがあり、どこが競合より優れているかを知る必要がある。
  - 製造業なら、仕入れ・製造・出荷・販売/マーケティング・アフターサービスという一連の流れが「主活動」。それを後方から支える全般管理・人事労務・技術開発・調達が「支援活動」。これらを通じて付加価値を生み、マージン（利益）を得る。
  - どの活動が付加価値を大きく生み、どこが他社より優れ／劣っているかを見る枠組みが「バリューチェーン（価値連鎖）」。マイケル・ポーターが著書『競争優位の戦略』で提唱した。
  - 競合より優れた商品や低価格を提供できるなど、競争上の優位性を「競争優位」という。バリューチェーンで強み・弱み・付加価値の所在を明らかにすることが、経営戦略・マーケティング戦略立案の第一歩。
- 用語・人名・文献: 主活動、支援活動、付加価値、マージン、バリューチェーン（価値連鎖）、競争優位、フレームワーク（枠組み）、マイケル・ポーター『競争優位の戦略』
- 図表「自社の競争優位はどの活動にあるか？」（p.31）:
  - 上段の支援活動（横帯4本）: 全般管理（インフラストラクチャー）／人事・労務管理／技術開発／調達活動
  - 下段の主活動（縦5列、左から右）: 購買物流 → 製造 → 出荷物流 → 販売・マーケティング → サービス
  - 右端の矢じり部分が「マージン」
  - まとめ枠: バリューチェーンに沿って探せば自社の競争優位が明らかになる
- マーカー: なし

### 10「コア・コンピタンス」で競争優位を確かなものに（p.32〜33）

小見出し: 他社より圧倒的に優れた能力とは／組織としての能力にも競争優位がある

- 要点:
  - バリューチェーンに弱みがあっても、苦手・非効率な分野はアウトソーシング（外部委託）できる。アップルも iPhone の製造はアジアの企業に任せ、企画・設計・デザイン・マーケティングに経営資源を集中している。
  - 競合より圧倒的に優れた得意分野・能力（独自の技術・ノウハウ・アイデアなど）を「コア・コンピタンス」という。提唱者はゲイリー・ハメル（本文表記「ゲイリー・ハメル」）。はっきりしたコア・コンピタンスを持ち、会社として育てることがまず大切。
  - 特別な技術がなくても、対応のスピード・効率性・品質管理などで優れた会社がある。こうした組織としての能力を「ケイパビリティ」という。
  - コア・コンピタンスとケイパビリティを相互に連動させ、バリューチェーンの活動に活かした会社が競争優位になる。
- 用語・人名: アウトソーシング（外部委託）、経営資源、コア・コンピタンス、ケイパビリティ、ゲイリー・ハメル、アップル、iPhone
- 図表「コア・タンピタンス、ケイパビリティとは」（p.33。図タイトルは原文どおり「タンピタンス」と印刷されている）:
  - 上の箱: コア・コンピタンス（特別な技術、ノウハウ、アイデアなど）
  - 下の箱: ケイパビリティ（対応のスピード、効率性、品質管理など）
  - 2つの箱を「連動させる」と書いた循環矢印で結んでいる。
  - 中央に「コア・コンピタンスの特徴」3つ（円）: 顧客にベネフィットを提供する能力（58ページ参照）／競争相手に真似できない能力／多様な市場に応用できる能力
  - まとめ枠: コア・コンピタンスとケイパビリティを連動させて競争優位を確かなものにする
- マーカー: なし

### 11「カネのなる木」を育てる法（p.34〜35）

小見出し: 経営資源の配分には「事業ポートフォリオ」／商品やサービスごとの戦略がわかる「PPM」

- 要点:
  - 戦略事業単位の設定と、どの事業にヒト・モノ・カネ（経営資源）をどれだけ割り当てるかは、全社レベルの経営戦略の一環。その判断材料が「事業ポートフォリオ」。同じ手法で商品・サービスの資源配分も考えられる。
  - 「プロダクト・ポートフォリオ・マネジメント（PPM）」は、ボストン・コンサルティング・グループの一般的な手法。市場成長率と占有率（シェア）のマトリクスに商品をプロットする。
  - 4つの枠ごとの戦略:
    - 花形: 成長率・シェアともに高い。シェアを維持して「カネのなる木」を目指す。
    - カネのなる木: 成長は鈍いがシェアが高く、コストがかからず利益が大きい収益源。できるだけ長く大きな利益を上げる。
    - 問題児: 成長率が高くコストがかかるが、シェアが低く利益が出ない。経営資源を注いで花形にするか、撤退するかを判断する。
    - 負け犬: 成長率・シェアともに低い。利益を上げる方法を考えるか、思い切って撤退するか判断する。
  - 事業ポートフォリオとして見れば、花形事業と、いずれ花形にする問題児事業に資源を配分する判断ができる。
- 用語・フレームワーク: 事業ポートフォリオ、ヒト・モノ・カネ、PPM（プロダクト・ポートフォリオ・マネジメント）、ボストン・コンサルティング・グループ、市場成長率、市場占有率（シェア）、花形（スター）、問題児（ワイルド・キャット）、カネのなる木（キャッシュ・カウ）、負け犬（ドッグ）
- 図表「市場成長率と市場占有率に応じてプロットする（ボストン・コンサルティング・グループによるPPM）」（p.35）:
  - 2×2マトリクス。
  - 横軸は市場占有率で、左が高、右が低。縦軸は市場成長率で、上が高、下が低。
  - 左上: 花形（スター）／右上: 問題児（ワイルド・キャット）
  - 左下: カネのなる木（キャッシュ・カウ）／右下: 負け犬（ドッグ）
  - まとめ枠: 商品やサービスを4つの枠のどれかにプロットすると、とるべき戦略がわかる
- マーカー: なし

### 12「アンゾフのマトリクス」に学ぶ成長戦略（p.36〜37）

小見出し: 「経営戦略の父」が取り入れたものとは／製品と市場をマトリクスで考えてみると

- 要点:
  - 「経営戦略」という言葉の「戦略（ストラテジー）」は、もともと軍事用語。大局的な視点から戦争全体を有利に進める方法を指す。これを企業経営に取り入れたのが「経営戦略の父」イゴール・アンゾフ。
  - 「アンゾフのマトリクス」は、事業の「製品」と「市場」をそれぞれ「既存」と「新」に分け、4つの組み合わせから成長戦略を導く。
  - 市場浸透戦略（既存市場×既存製品）: シェアを伸ばす。既存顧客に多く買ってもらう、競合の顧客を引き寄せる、新顧客を開拓するなど。
  - 市場開拓戦略（新市場×既存製品）: 国内販売していた製品の海外進出などが典型例。
  - 製品開発戦略（既存市場×新製品）: 既に支持を受けている市場に新製品を投入する。
  - この3つは実績ある製品・市場をベースにするので受け入れられやすい。3つともとれない場合はどうするかは次項に続く。
- 用語・人名: 経営戦略、戦略（ストラテジー）、イゴール・アンゾフ、アンゾフのマトリクス、市場浸透戦略、市場開拓戦略、製品開発戦略、多角化戦略
- 図表「4つの組み合わせから4つの戦略が導き出される」（p.37）:
  - 2×2マトリクス。横軸は製品（既存／新）、縦軸は市場（既存／新）。
  - 既存市場×既存製品: 市場浸透戦略／既存市場×新製品: 製品開発戦略
  - 新市場×既存製品: 市場開拓戦略／新市場×新製品: 多角化戦略
  - まとめ枠: 「製品」「市場」、「既存」「新」の組み合わせから企業が成長するための戦略が発見できる
- マーカー: なし

### 13「統合」「多角化」も戦略のうち（p.38〜39）

小見出し: 他社と事業統合する「統合的成長」／新しい市場に新製品を投入する「多角的成長」

- 要点:
  - 成長戦略には、既存製品・市場をベースにしない方法もある。近年は、まったく新しい事業分野に進出するとき、その分野の既存企業を買収する方法もよくとられる。
  - 成長の方法は「集中的成長」「統合的成長」「多角的成長」の3つ。既存事業をベースにするのが集中的成長（前項の3戦略）。
  - 統合的成長: 他社の事業も視野に入れて統合する。3種類がある。
    - 後方統合: 仕入先など供給を担う他社との統合
    - 前方統合: 流通を担ってきた他社との統合
    - 水平統合: 競合他社の事業の統合
  - 多角的成長（多角化戦略）: 新しい市場に新しい製品を投入する。ほぼゼロからのスタートなので格段にリスクが高いが、有望な市場を選べるので成功すればハイリターン。3種類がある。
    - 同心円的多角化戦略
    - 水平的多角化戦略
    - コングロマリット的多角化戦略
  - 経営資源を浪費する既存事業は、合理化や廃止を検討することもある。
- 用語: 集中的成長、統合的成長、後方統合、前方統合、水平統合、多角的成長、同心円的多角化戦略、水平的多角化戦略、コングロマリット的多角化戦略、買収、ハイリスク・ハイリターン【曖昧：本文は「ハイリターン」のみ確認】
- 図表「あなたの会社はどの成長戦略？」（p.39）:
  - 3行の表（左列＝状況、中列＝成長の型、右列＝具体的戦略）。
    - 既存の事業で成長する → 集中的成長 → 市場浸透戦略、市場開拓戦略、製品開発戦略など
    - 他社の事業を統合する → 統合的成長 → 後方統合、前方統合、水平統合など
    - 新市場に新製品を投入する → 多角的成長 → 同心円的多角化戦略、水平的多角化戦略、コングロマリット的多角化戦略など
  - まとめ枠: 経営資源を浪費する既存事業は合理化・廃止の選択も
- マーカー: なし

### 14 事業の戦略は「環境分析」から（p.40〜41）

小見出し: 外部環境分析で「機会」と「脅威」を見極める／内部環境分析では「強み」と「弱み」をチェック

- 要点:
  - 経営戦略で事業の経営資源・成長戦略が決まったら、戦略事業単位の戦略を立てる。最初にすることは分析（22ページ参照）。
  - 事業には会社の外側の環境と内側の環境がある。それぞれ「外部環境分析」「内部環境分析」で分析する。
  - 外部環境分析では、利益を上げられる「機会」と、売上や利益を下げる「脅威」を見極める。
  - 内部環境分析では自社の「強み」と「弱み」をチェックする。機会があっても活かせる強みがなければ成功しない。例えば、市場に「不足しているもの」がある機会に対し、「商品開発力が高い」という強みがあれば機会を活かせるが、弱ければ成功はおぼつかない。
  - 強み・弱み・機会・脅威から外部環境と内部環境を分析する手法が「SWOT分析」。
- 用語・フレームワーク: 外部環境分析、内部環境分析、機会（Opportunity）、脅威（Threat）、強み（Strength。本文の綴りは「Strengh」）、弱み（Weakness）、SWOT分析
- 図表「「外部環境分析」「内部環境分析」をする」（p.41）:
  - ツリー図。外部環境分析 → 機会／脅威、内部環境分析 → 強み／弱み。
  - 機会の説明: ①不足しているものを供給する ②新しい方法、優れた方法で供給する ③新しい商品やサービスを供給する
  - 脅威の説明: 事業にとって、不利な傾向や変化
  - 強みの説明: 事業の内部的な強み。弱みの説明: 事業の内部的な弱み。
  - まとめ枠: 強み＝Strengh、弱み＝Weakness、機会＝Opportunity、脅威＝Threatから「SWOT分析」と呼ぶ
- マーカー:
  - ピンク 小見出し「外部環境分析で「機会」と「脅威」を見極める」（p.40）
  - ピンク（枠を囲む線）p.41 のまとめ枠「強み＝Strengh…「SWOT分析」と呼ぶ」

### 15「SWOT分析」で環境に応じた戦略を導き出す（p.42〜43）

小見出し: 環境と影響の組み合わせで書き出していく／「クロスSWOT分析」なら戦略が導き出される

- 要点:
  - SWOT分析では、縦を「内部環境」「外部環境」、横を「好影響」「悪影響」とした表に、具体的な強み・弱み・機会・脅威を書き出す。例えば「商品開発力が高い」は強み、「国内で消費量が落ちている」は脅威。
  - 「クロスSWOT分析」は、強み・弱みと機会・脅威をマトリクスにして、4つの戦略を導く。SWOT分析のよいところは、分析にとどまらず具体的な戦略が立てられる点にある。
  - 強み×機会の例: 「商品開発力が高い」×「新興国の市場が伸びている」なら積極的攻勢戦略。「新興国のニーズに特化した製品を開発する」といった具体策になる。
  - 強み×脅威の例: 「広告宣伝がうまい」会社が「消費が落ちている」脅威に直面したら、差別化戦略として魅力的なCMを継続的に打つ。
  - 弱み×機会は段階的施策戦略（現状を維持しつつ徐々に対策を講じる）。弱み×脅威は専守防衛または撤退戦略（徹底的に守るか、思い切って撤退する）。
- 用語・フレームワーク: SWOT分析、クロスSWOT分析、好影響、悪影響、積極的攻勢戦略、差別化戦略、段階的施策戦略、専守防衛または撤退戦略

### 17 戦略の実行は「マッキンゼーの7S」で（p.46〜47）

### 20 マーケティング・リサーチ手法のいろいろ（p.52〜53）

  - ネットの普及で官公庁の統計など2次データは入手しやすくなったが、2次データだけで足りるケースはまれ。1次データの収集では「調査手法」と「調査手段」を決める。
  - 調査手法は5つ（右の表）。マーケティング・リサーチ＝アンケートのイメージが強いが、観察や実験が有効な場合もある。
  - 調査手段（どんな道具立てで調査するか）には3つがある。
    - 質問票: おなじみのもの。
    - 質的調査: 量的でない、観察調査やインタビューの手段。
    - 機械装置: ICカードやGPSその他の最新機器を使った調査。

    - サンプリング単位: 母集団をどこまでとするか。
    - サンプル・サイズ: 何件のデータをとるか。
    - サンプリング手順: サンプルをどう抽出するか。
  - 「コンタクト方法」（調査対象と接触する方法）には、郵送質問票・電話インタビュー・対面インタビューのほか、ウェブ上に質問票を載せたりチャットを使ったりする「オンライン・インタビュー」がある。

  - フォーカス・グループ調査: 特定の条件によって選ばれた6〜10人のグループに討論をしてもらう

### COLUMN 小さな会社でも使える「弱者の戦略」とは？（p.54）

- 要点:
  - 中小企業が大企業と戦える弱者の戦略として「ランチェスターの法則」が有名。イギリスの航空技術者フレデリック・ランチェスターが、第一次大戦中の空中戦を分析して勝ち方を法則にまとめたもの。1950年代から日本でも経営戦略に応用され、「ランチェスター戦略」「ランチェスター経営」と呼ばれる。
  - 第1法則と第2法則がある。有名なのは、大企業に対して中小企業が戦いを挑める弱者の戦略である第1法則。
  - 第1法則の戦略は5つ: ①局地戦 ②一騎討ち ③接近戦 ④一点集中 ⑤陽動作戦。
  - 経営戦略に置き換えると次のようになる。
    - 局地戦: 小さな市場で戦う。
    - 一騎討ち: 競争相手の少ない市場で戦う。
    - 接近戦: 広告より販売促進に重点を置く。
    - 一点集中: 小さな会社でも全経営資源を小さな市場に集中すれば、大企業がその市場に投下する資源を上回り、勝てる可能性がある。
  - 第2法則は強者の戦略で、第1法則の裏返しのようなもの。
- 用語・人名: ランチェスターの法則、フレデリック・ランチェスター、ランチェスター戦略、ランチェスター経営、第1法則（弱者の戦略）、第2法則（強者の戦略）、局地戦、一騎討ち、接近戦、一点集中、陽動作戦
- 図表: 5つの戦略を列挙した枠のみ。
- マーカー: なし
