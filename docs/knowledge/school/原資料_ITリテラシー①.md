## ハードウェアとソフトウェア

### 単元1 コンピュータの種類（p.12〜15）

- 学習内容: コンピュータ、高速性、記憶性、正確性、汎用性、PC、サーバ、汎用コンピュータ、タブレット端末、ウェアラブル端末、携帯情報端末
- 小見出し: 「コンピュータとは？」「コンピュータの形状による分類」「コンピュータの役割による分類」
- 要点:
  - コンピュータの定義を IT用語辞典「e-Words」から引用し、決められた手順に従って複雑な計算を自動で行う電気機械だと説明している。電子回路を使ってデジタルデータの入出力・演算・変換を連続して行い、手順を記述して与えればいろいろな用途に使える。
  - コンピュータには他の道具より優れた4つの特性がある。高速性（大量データを高速計算）、記憶性（大量データを記憶）、正確性（正確に計算）、汎用性（プログラムを変えれば多様な処理ができる）。
  - 役割による分類では、まず PC（個人用の小型コンピュータ）とサーバ（ネットワーク経由で他のコンピュータにサービスを提供する小・中型コンピュータ。1台に複数のサーバ機能を持たせることもできる）を挙げる。
  - 汎用コンピュータ（汎用機、ホストコンピュータ）は多くの端末がつながる大型機。1980年代までは汎用機と端末の組合せが主流だったが、今はサーバとPCの組合せが主流。ほかにタブレット端末（携帯情報端末の一つ）とウェアラブル端末（身につけて使う。GPS機能を持つものなど）がある。
- 主な用語: 高速性、記憶性、正確性、汎用性、PC（パソコン、パーソナルコンピュータ）、サーバ、汎用コンピュータ（汎用機、ホストコンピュータ）、端末、タブレット端末、携帯情報端末、ウェアラブル端末、全地球測位システム（GPS）
- 図表:
  - コンピュータの処理の流れ（p.12）: 「データの入力（データA）→ データの演算・変換（『電子回路』＋『詳細な処理手順』）→ データの出力（データB）」を矢印でつないだ図。
  - コンピュータの形状による分類（p.13）: 写真・イラスト11点。デスクトップ型PC、ノート型PC、タブレット、スマートフォン、スマートテレビ、スマートスピーカー、スマートグラス、スマートイヤホン、スマートウォッチ、スマートバンド（腕輪）、スマートリング（指輪）。

### 単元2 コンピュータの基本構成（p.16〜19）

- 学習内容: ハードウェア、入力装置、出力装置、記憶装置、演算装置、制御装置、ソフトウェア、システムソフトウェア、応用ソフトウェア
- 小見出し: 「ハードウェアとソフトウェアとは？」「ハードウェアの具体例」「装置間の制御の流れ、データの流れ」「代表的なIoTデバイスの部品」「オペレーティングシステムとは？」「代表的なオペレーティングシステム」「代表的なアプリケーションソフト」
- 要点:
  - ハードウェアは、コンピュータを構成する機器をまとめた呼び名。五つの装置（入力・出力・記憶・演算・制御）に分かれ、演算装置と制御装置が CPU（中央処理装置）にあたる。
  - ソフトウェアは、コンピュータを動かすプログラムやデータをまとめた呼び名。システムソフトウェア（ハードウェアを制御する。例: OS）と、応用ソフトウェア（その上で具体的な作業をする。例: ワープロソフト、表計算ソフト）に分かれる。
  - IoTデバイス（インターネットにつながり、互いに情報をやり取りする機器）の部品には、センサー（測った値を電気信号にして出力する）とアクチュエーター（電気信号を力学的な運動に変える。モーターは回転運動に、シリンダは直進運動に変える）がある。
  - OS は、ハードウェアの動作を制御し、利用者がコンピュータを使える環境を用意する。OS のおかげで、利用者はハードウェアの違いを意識しないで応用ソフトを使える。OS の機能は、ジョブ管理、タスク管理、記憶管理（実記憶管理・仮想記憶管理）、入出力管理、データ管理（ファイルシステム）、ユーザ管理。
  - 代表的なOSとして Windows（マイクロソフト社）、macOS（アップル社）、Linux（リーナス・トーバルズ氏が中核部分を開発した UNIX系の OSS）、iOS（アップル社。スマホ・タブレット用）、Android（グーグル社。OSS）を挙げている。
- 主な用語: 入力装置、出力装置、記憶装置（主記憶装置・補助記憶装置）、演算装置、制御装置、CPU（中央処理装置）、システムソフトウェア、応用ソフトウェア（アプリケーションソフト）、IoT、センサー（光・磁気・加速度・ジャイロ・超音波・温湿度）、アクチュエーター（モーター、シリンダ）、オペレーティングシステム（OS）、ジョブ管理、タスク管理、実記憶管理、仮想記憶管理、入出力管理、データ管理、ユーザ管理、オープンソースソフトウェア（OSS）、ワープロソフト、表計算ソフト、プレゼンテーションソフト（オフィスツール）、データベースソフト、Webブラウザ（WWWブラウザ、プラグイン）、グラフィックスソフト（ペイント系、ドロー系）
- 図表:
  - 五つの装置の表（p.16）: 列は「装置｜概要｜具体例」。入力装置（キーボード、マウス）、出力装置（ディスプレイ、プリンター）、記憶装置（メインメモリ＝主記憶装置／ハードディスク・光ディスク＝補助記憶装置）、演算装置・制御装置（CPU）。
  - ソフトウェアの表（p.16）: 列は「分類｜概要｜具体例」。システムソフトウェア（OS）、応用ソフトウェア（ワープロ、表計算ソフトなど）。
  - ハードウェアの具体例（p.17）: ディスプレイ、キーボード、マウス、CPU、メインメモリ、ハードディスク、光ディスク、プリンターのイラスト。
  - 装置間の制御の流れ、データの流れ（p.17）: 制御装置から入力・記憶・演算・出力の各装置へ「制御の流れ」（実線の矢印）が出ている。「データの流れ」（点線の矢印）は、入力装置→記憶装置、記憶装置⇔演算装置、記憶装置→出力装置。
  - IoT部品のイラスト（p.18）: モーター、シリンダ、超音波センサー。OS を「私が代わりに指示します！」と話すキャラクターで表したイラスト。
  - OS のロゴ（p.19）: Windows、macOS、Linux（ペンギン）、iOS、Android。

### 単元3 プロセッサとメモリ（p.20〜23）

- 学習内容: CPU、マルチコアプロセッサ、クロック周波数、レジスタ、キャッシュメモリ、メインメモリ、SSD、HDD、CD、DVD、BD、USBメモリ、SDカード
- 小見出し: 「プロセッサの仕組み」「半導体メモリの分類」「代表的な記憶装置と記憶階層」
- 要点:
  - CPU は、制御装置・演算装置・レジスタを載せた「プロセッサコア」を持つ。コアを複数載せた CPU をマルチコアプロセッサと呼ぶ。キャッシュメモリは、高速なレジスタと低速なメインメモリの間に置いて速度差を埋める。コアの中にある L1、コアの外にある L2・L3 がある。
  - CPU の性能は七つの要素で決まる。コア数、スレッド数（論理的なコア数）、クロック周波数（Hz）、データバス数（32本なら32ビットCPU、64本なら64ビットCPU。64ビットの方が高性能）、L1・L2・L3キャッシュの容量。
  - 半導体メモリは性質で分けると、揮発性メモリ（電源を切ると内容が消える。メインメモリの DRAM、キャッシュメモリの SRAM）と不揮発性メモリ（フラッシュメモリ。SSD や USBメモリ）がある。用途で分けると RAM（読み書き自由）と ROM（読み出しだけ）。
  - 記憶階層: 上から順にレジスタ、L1、L2、L3、メインメモリ、SSD・HDD＋ディスクキャッシュ。上ほど速くて高価、下ほど遅くて安価で容量が大きい。SSD は衝撃に強く消費電力が少なく、HDD に代わる装置。HDD は磁気ディスクを使い、安価で大容量にしやすい。
  - 光ディスク: CD は近赤外レーザー（波長780nm）で 700MB（音楽80分）。DVD は赤色レーザー（650nm）で CD 6枚分（片面1層 4.7GB、両面1層 9.4GB、片面2層 8.54GB、両面2層 17.08GB）。BD は青紫色レーザー（405nm）で CD 35枚分・DVD 5枚分（片面1層 25GB、片面2層 50GB、BDXL 片面3層 75GB、BDXL 片面4層 100GB と印刷されている）。
- 主な用語: CPU、プロセッサコア、マルチコアプロセッサ、キャッシュメモリ（L1/L2/L3）、コア数、スレッド数、クロック周波数、データバス、揮発性メモリ、不揮発性メモリ、DRAM、SRAM、フラッシュメモリ、SSD（ソリッドステートドライブ）、HDD（ハードディスクドライブ）、ディスクキャッシュ、RAM、ROM、記憶階層、光ディスク、CD／DVD／BD（ROM・R・RW／RAM／RE）、BDXL、USBメモリ、SDカード・miniSDカード・microSDカード
- 図表:
  - マルチコアプロセッサの構造図（p.20）: CPU＝プロセッサコア2つ（それぞれに制御装置・演算装置・レジスタ・L1キャッシュ）＋コアごとの L2キャッシュ＋共有の L3キャッシュ。
  - CPU 性能の七要素の表（p.21）: 列は「要素｜説明」。
  - 半導体メモリの分類（p.21）: 【性質による分類】揮発性／不揮発性、【用途による分類】RAM／ROM。
  - 記憶階層の三角形（p.22）: 頂点がレジスタで、底辺が SSD・HDD＋ディスクキャッシュ。矢印で「動作速い・高価」から「動作遅い・安価・容量大」へ向かう。
  - 光ディスクの表（p.23）: 行はレーザー光の種類（近赤外 780nm／赤色 650nm／青紫色 405nm）、列は記録方式（再生専用型／追記型／書換え型）。CD-ROM・CD-R・CD-RW、DVD-ROM・DVD-R・DVD-RAM、BD-ROM・BD-R・BD-RE。
- マーカー: なし

### 単元4 ソフトウェアの利用（p.24〜27）

- 学習内容: マルチユーザ、マルチタスク、スレッド、OSアップデート、ファイルシステム、絶対パス、相対パス、バックアップ、ソフトウェアライセンス
- 小見出し: 「システムソフトウェアの技術」「システムソフトウェアの更新」「ファイルシステム」「データのバックアップ」「ソフトウェアライセンス」
- 要点:
  - OS には、複数の利用者が1台を同時に使えるマルチユーザ、CPU の利用時間を細かく分けて複数のアプリが同時に動くように見せるマルチタスク（マルチプロセス、マルチプログラミング）、一つのアプリに複数のコアの利用時間を同時に割り当てるマルチスレッドの技術がある。
  - OS アップデートは、新機能の追加や不具合の修正のために開発元が公開するプログラムを入れて、OS を最新に保つこと。注意点は、重要データのバックアップを取っておくこと、ノートPC・スマホではバッテリ残量を確認すること、時間に余裕をもって行うこと。
  - ファイルシステムは、ルートディレクトリ（最上位）からサブディレクトリ、ファイルへと木の形でつながる。絶対パスはルートから、相対パスはカレントディレクトリ（今いる場所）から目的の場所までの経路を書く。
  - バックアップはデータのコピーを作ること、リストアはバックアップから元に戻すこと。注意点は、定期的に取る、記録媒体と保管場所を適切に選ぶ（災害や盗難に備える）、2〜3世代分を世代管理する、の三つ。手法はフル（全データ）、差分（前回のフル以降の更新分）、増分（前回のフル・増分以降の更新分）の三つ。
  - ソフトウェアライセンスは、ソフトウェアを使うときに守ることを定めた文書で、使用許諾契約（EULA）に書かれていることが多い。無償のもの（フリーソフト、PDS、OSS）、シェアウェア（試用期間の後は料金が必要）、有償のもの（シュリンクラップ契約、ボリュームライセンス契約、アクティベーション、サブスクリプション）がある。
- 主な用語: マルチユーザ、マルチタスク（マルチプロセス、マルチプログラミング）、マルチスレッド、OSアップデート、ファイルシステム、ルートディレクトリ、カレントディレクトリ、サブディレクトリ、ディレクトリ（フォルダ）、絶対パス、相対パス、バックアップ、バックアップファイル、リストア、世代管理、フルバックアップ、差分バックアップ、増分バックアップ、使用許諾契約（EULA）、無償ソフトウェアライセンス、フリーソフトウェア（フリーウェア、フリーソフト）、パブリックドメインソフトウェア（PDS。著作権を放棄したもの）、オープンソースソフトウェア（OSS）、シェアウェア、有償ソフトウェアライセンス、シュリンクラップ契約、ボリュームライセンス契約、アクティベーション、サブスクリプション
- 図表:
  - ディレクトリの木構造（p.25）: ルート「/」の下に D1・F2・D2。D1 の下に D3（その下に F3）と F1。D2（カレントディレクトリ）の下に D4。

## データベース

### 単元5 データベースの構築（p.28〜31）

- 学習内容: データベース、関係モデル、テーブル、レコード、フィールド、データベース設計、E-R図、主キー、外部キー、正規化、インデックス
- 小見出し: 「データベースとは？」「データベース設計」
- 要点:
  - データベース（DB）は、大量のデータを規則を決めて整理したもの。導入すると、データを一元管理できるので矛盾が起きず（一貫性）、重複がなくなるので無駄なく管理できる。
  - データモデルには、関係モデル（リレーショナルモデル。表形式）、階層モデル（親と子が1対多）、ネットワークモデル（親と子が多対多）がある。関係モデルでは、関係（リレーション）をテーブル、組（タプル）をレコード、属性（アトリビュート）をフィールドとも呼ぶ。
  - データベース設計は3段階で進める。①概念設計: E-R図で、エンティティ（長方形）、リレーションシップ（ひし形）、属性（だ円）を整理する。②論理設計: テーブルを決め、レコードを一意に特定する主キーと、他のテーブルの主キーの値を持つ外部キーを決め、正規化する。③物理設計: データ型やインデックス（検索キー）を決め、テーブル設計書を作る。
  - 正規化の手順: 第一正規化（同じ意味の複数フィールドをまとめる／他のフィールドから求められるものを削除する）→ 第二正規化（主キーの一部のフィールドに着目してテーブルを分ける）→ 第三正規化（主キー以外のフィールドに着目してテーブルを分ける）。
- 主な用語: データベース（DB）、データの一貫性、データモデル、関係モデル（リレーショナルモデル）、階層モデル、ネットワークモデル、関係（リレーション）、組（タプル）、属性（アトリビュート）、テーブル、レコード、フィールド、概念設計、論理設計、物理設計、E-R図、エンティティ、リレーションシップ、主キー、外部キー、正規化（第一〜第三正規化）、インデックス（検索キー）、データ型、制約

### 単元7 ネットワークの基本構成（p.36〜39）

- 要点:
  - ネットワークは、コンピュータや通信機器をつないでデータをやり取りする通信網。LAN（構内通信網。学校・職場・家庭など限られた範囲）と WAN（広域通信網。通信事業者が持ち、離れた LAN どうしをつなぐ）に分かれる。LAN には有線LAN（速くて機器の場所を特定しやすいが、設置場所を変えにくい）と無線LAN（設置場所を変えやすいが、電波による制限があり、機器の場所を特定しにくい）がある。

  - 通信プロトコルは、通信のための約束事や手順。ポート番号は、上位プロトコルに付く番号で、データの送り元や送り先のアプリの種類を特定できる（表中のポート番号はウェルノウンポート番号と呼ぶ）。

### 単元8 インターネット技術（p.40〜43）

- 学習内容: 通信サービス、Webサービス、電子メールサービス、ファイル転送サービス、TCP/IP、IPv4、IPv6、ネットワークアドレス、サブネットマスク、CIDR

- 要点:

  - 脅威は情報資産に損失を与える原因、脆弱性は脅威の発生・拡大の要因となる弱点や欠陥、リスクは脅威と脆弱性によって情報資産に生じる損失。「情報資産 × 脅威 × 脆弱性 ＝ リスク」。
  - リスクマネジメントは、起こりうるリスクへの対応を前もって決めて管理すること。①リスクアセスメント（リスク特定 → リスク分析 → リスク評価。発生頻度や影響の大きさで評価する）、②リスク対応（リスク回避、リスク共有（リスク移転・リスク分散）、リスク保有）の順に進め、対応したら①に戻る。
  - 脅威は3種類に分かれる。人的脅威（紛失、漏えい、誤操作、ソーシャルエンジニアリング（なりすまし、盗み見））、技術的脅威（マルウェアによる攻撃（コンピュータウイルス、DoS攻撃）、パスワードクラック（辞書攻撃、総当たり攻撃））、物理的脅威（災害、破壊）。過去の事故では人的脅威が原因のケースが最も多い。
  - 情報セキュリティマネジメントは、組織の考え方を文書にして実施・管理すること。情報セキュリティポリシーを全従業員に守らせるために ISMS（情報セキュリティマネジメントシステム）を導入し、機密性・完全性・可用性のバランスを保つよう PDCA サイクルで運用する。ISMS適合性評価制度を使えば、第三者機関に評価・認証してもらえる。

### 単元11 暗号技術（p.52〜55）

- 学習内容: 暗号化、復号、共通鍵暗号方式、共通鍵、公開鍵暗号方式、公開鍵、秘密鍵、認証局、デジタル証明書、ハイブリッド暗号方式、セッション鍵、WPA2
- 小見出し: 「暗号技術の必要性」「共通鍵暗号方式」「公開鍵暗号方式」「ハイブリッド暗号方式（セッション鍵暗号方式）」「暗号技術の応用」「無線LANの暗号化」
- 要点:
  - 暗号技術は、平文を暗号文にする暗号化と、暗号文を平文に戻す復号からなる。方式には、共通鍵暗号方式、公開鍵暗号方式、ハイブリッド暗号方式（セッション鍵暗号方式）がある。盗聴や窃取は防げないが、解読に時間がかかるので漏えいの可能性を下げられる。
  - 共通鍵暗号方式は、暗号化と復号に同じ鍵を使う。処理が簡単なので暗号通信が速いが、通信相手ごとに違う鍵が必要なので鍵の管理が面倒。鍵をどう渡すかをしっかり考える必要がある（悪い例: メールに添付、郵便や宅配便。良い例: 直接手渡し。ただし現実的ではない）。
  - 公開鍵暗号方式は、公開鍵と秘密鍵の組を使い、受信者の公開鍵で暗号化して受信者の秘密鍵で復号する。通信相手全員に同じ公開鍵を使えるので鍵の管理は簡単だが、暗号通信は遅い。受信者のなりすましを防ぐために、第三者機関の認証局（CA）がデジタル証明書（電子証明書、公開鍵証明書）を発行する。
  - ハイブリッド暗号方式は、共通鍵（セッション鍵）を公開鍵暗号方式で送り、その後の暗号通信は共通鍵暗号方式で行う。鍵の送付は1回だけなので公開鍵方式の遅さは問題にならず、通信は速い。CA によって受信者のなりすましも防げる。
  - 応用例は、ディスク暗号化（SSD や HDD の記憶装置全体を暗号化する）とファイル暗号化。無線LAN の暗号化には WPA2（2004年に Wi-Fiアライアンスが発表。個人向けの WPA2-PSK と、RADIUS サーバを使う企業向けの WPA2-EAP）と WPA3（2018年に発表。IoT や 5G とともに広がる見込み）がある。
- 主な用語: 暗号技術、平文、暗号文、暗号化、復号、共通鍵暗号方式、共通鍵、公開鍵暗号方式、公開鍵、秘密鍵、ハイブリッド暗号方式（セッション鍵暗号方式）、セッション鍵、認証局（CA）、デジタル証明書（電子証明書、公開鍵証明書）、ディスク暗号化、ファイル暗号化、WPA2、WPA2-PSK（パーソナル）、事前共有鍵（PSK）、WPA2-EAP（エンタープライズ）、RADIUS サーバ、WPA3
- 図表:
  - 共通鍵暗号方式の図（p.52）: 送信者が平文「絶対に内緒にしてね」を共通鍵で暗号化して暗号文（QWE/ASD/ZXC）にし、転送する。受信者が同じ共通鍵で復号する。
  - 公開鍵暗号方式の図（p.53）: 送信者が受信者の公開鍵で暗号化して暗号文（RTY/FGH/VBN）にし、転送する。受信者が自分の秘密鍵で復号する。
  - デジタル証明書の記載項目の表（p.53）: 列は「記載項目｜概要」。バージョン情報（v1・v2・v3）、シリアル番号、署名アルゴリズム、発行者名（認証局の名前）、有効期間、証明者名（所有者の名前）、公開鍵アルゴリズム、公開鍵情報。

### 単元12 認証技術（p.56〜59）

- 学習内容: パスワード認証、多要素認証、ワンタイムパスワード、デジタル署名、利用者認証、メッセージ認証、ハッシュ関数、ハッシュ値、時刻認証、時刻印
- 小見出し: 「認証技術の必要性」「利用者ID・パスワードによる認証」「デジタル署名」「時刻認証（タイムスタンプ認証）」
- 要点:
  - 認証技術は、利用者やデータに間違いがないことを確かめる仕組み。認証方式には、利用者認証（なりすましの防止）、メッセージ認証（改ざんの検知）、時刻認証（ある時刻にデータが存在し、それ以降変更されていないことの保証）がある。
  - パスワード認証は、利用者だけが知る文字列による認証。仕組みが簡単なので広く使われている。運用規則として、作り方（英数字や記号を組み合わせ、8文字以上）、変更（使い回さず、定期的に変える）、記録（人に見える場所に置かない。パスワードリマインダは推測されにくいものにする）、緊急時（漏れたらすぐ管理者に連絡し、そのパスワードを無効にする）を挙げている。
  - 多要素認証は、知識（パスワード）、所持（ICカード）、生体（身体的特徴）を組み合わせる方法。二要素認証が広く使われている。ワンタイムパスワードには、チャレンジレスポンス認証（認証サーバから届く毎回違うチャレンジコードをもとにレスポンスコードを計算して送る）と、タイムシンクロナス認証（トークンが生成するワンタイムパスワードを使う）がある。
  - デジタル署名は、公開鍵暗号方式を使って利用者認証とメッセージ認証を行う。送信者は秘密鍵で暗号化し、送信者の公開鍵（デジタル証明書に含まれる）で復号する。ハッシュ関数は、データから固定長のハッシュ値（メッセージダイジェスト）を求める関数で、ハッシュ値から元のデータには戻せない。
  - 時刻認証（タイムスタンプ認証）では、時刻印業者の秘密鍵と公開鍵を使う。ハッシュ値に時刻印を加えた TSトークンを利用者が受け取り、あとでハッシュ値を比べて、その時刻から変更されていないことを確かめる。
