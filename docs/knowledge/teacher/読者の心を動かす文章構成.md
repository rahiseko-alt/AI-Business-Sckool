## 1. なぜ「いきなり書き始めてはいけない」のか？
- 人を動かす文章で重要なのは「書く作業」ではなく、その前の**「設計」**。
- マーケティングの視点では、文章の真の目的は「上手な日本語を書くこと」ではなく**「読者の行動を変えること」**。ライティングは想いを相手に届ける「架け橋」。
- 設計の4要素: **誰に**（ターゲット）／**何を伝えて**（メッセージ）／**どう感じてもらい**（心理的変化）／**最後に何をしてほしいのか**（具体的な行動）。
- ヒント: 「何を伝えるか」と同じくらい「どのように伝えるか」が重要。

## 2. 文章の「骨子（こっし）」：人を動かす4つのパーツ

| 要素名 | 役割 | 読者の反応 |
| --- | --- | --- |
| ① 主張 | 一番伝えたい結論を、短く言い切る | 「へぇ、そうなんだ」と興味を持つ |
| ② 理由 | なぜその主張が正しいのかを説明する | 「なるほど、納得できる」と腑に落ちる |
| ③ 具体例・証拠 | 理解を助け、納得感を高める材料を出す | 「本当だ！自分にもできそう」と信じる |
| ④ CTA（行動） | 相手に次にとってほしい行動を促す | 「よし、やってみよう」と動く |

- CTA: Call To Action の略。順番は 興味 → 納得 → 信頼 → 行動 という心理変化のプロセスに基づく。

## 3. 【実践例】「AI学習」をテーマにした4ステップ
1. 主張: AIは初心者でも使いこなせます。
2. 理由: 難しいコードは不要で、普段の日本語で指示できるからです。
3. 具体例: プログラミング未経験の学生がAIを使ってアプリを完成させた実績があります。
4. CTA: ぜひオープンキャンパスで、AIを使ったアプリ制作を体験してください。
- 統合例文（主張→理由→具体例→CTAの順につないだ文章）も掲載。

## 4. AI時代にこそ必要な「人間の設計力」
- 「誰に、何を、なぜ伝えるか」という目的設定と骨子を決めるのは人間の役割。AIに丸投げした文章は平均的で心に響かない。
- 人間が担当（設計力）: ターゲット選定／目的（促す行動）の設定／主張・理由・証拠の骨子の組み立て。
- AIが担当（生成力）: 骨子に基づく文章の書き起こし／ターゲットに合わせた言葉遣いの調整／SNS・メール・ブログなど媒体別の加工。
- AIへの指示出し例: 「以下の骨子をもとに、高校生向けのInstagram投稿文を作成してください。」＋ターゲット（進路に悩む高校生）／目的（オープンキャンパスへの申し込み）／主張／理由／具体例／CTA（プロフィールのリンクから申し込み）／トーン（やさしく、ワクワクするような表現）。

## 5. まとめ
- ライティングはSNS、メール、プレゼン、面接、商品説明にも使える「一生モノの武器」。
- 全体フロー: 1. 誰に？ → 2. 行動 → 3. 伝える内容 → 4. 構成（骨子） → 5. デザイン → 6. 発信 → 7. 効果測定。
- **「デザインの前にライティングがある」**。
- 明日から実践すべき4ステップ: いきなり書かず「誰に・何をしてほしいか」をメモ／4パーツで骨子／デザインや語彙より先に伝える順番を確認／発信後に読者が動いたか振り返る。
