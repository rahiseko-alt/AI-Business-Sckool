## 内容（スライド単位の見出しと要点。「⸻」で区切られていた単位ごと）

1. **WEBライティング — マーケティングに必要なライティング**（表紙）
2. **マーケティングとは？** — マーケティングでは、最初に考えます。誰（だれ）の行動（こうどう）を、どのように変（か）えたいのか？ 例: 商品を買ってほしい／学校に来てほしい／Instagramをフォローしてほしい／イベントに参加してほしい／アプリを使ってほしい。そのために、何を伝えるべきか？ どの方法で伝えるべきか？ を考えます。
3. **でも、考えただけでは相手に伝わらない** — 例「高校生にオープンキャンパスへ来てほしい」と目的を決めても、「来てほしい」と考えただけでは高校生は行動しない。Instagram、Webサイト、動画、ポスターなどを使って相手にメッセージを届ける必要がある。ここで必要になるのがライティング。
4. **ライティングとは？** — 目的に合わせて、伝える内容・順番・言葉を設計（せっけい）し、文章にすること。ただ日本語を上手に書くことではない。大切なのは、誰に／何を伝えて／どう感じてもらい／最後に何をしてほしいのか を考えて文章を作ること。
5. **なぜマーケティングにライティングが必要なのか？** — 同じ商品やサービスでも、伝え方が変わると受け取る人の感じ方も変わる。例「AIを勉強できます。」だけでは何が良いのか分からない。「プログラミング未経験でも、AIを使ってアプリを作れます。」と伝えれば「自分にもできるかもしれない」と感じる人がいる。何を伝えるかだけでなく、どのように伝えるかも重要。
6. **マーケティングとライティングの関係** — マーケティング: 誰に？ → どんな行動をしてほしい？ → そのために何を伝える？ → ライティング: 何を、どの順番で、どんな言葉で伝える？ → デザイン: どう見せれば伝わりやすい？ → 発信: Instagram／Webサイト／動画／メール／ポスター → 効果測定（こうかそくてい）: 本当に相手の行動は変わった？
7. **文章を書く前に「骨子」を作る** — いきなり文章を書かない。まず骨子（こっし）＝文章の骨組みを作る。基本は4つ。
8. **基本の骨子 ① 主張（しゅちょう）** — 一番伝えたいことを短く言う。例「AIは初心者でも使えます。」
9. **② 理由** — なぜそう言えるのか？ 例「日本語でAIに指示できるからです。」
10. **③ 具体例・証拠（しょうこ）** — 相手が理解・納得する材料を出す。例「実際に、プログラミング未経験の学生もAIを使ってアプリを作っています。」
11. **④ CTA** — Call To Action の意味。日本語では「相手に次にしてほしい行動」。例「オープンキャンパスで実際に体験してみてください。」
12. **4つをつなげる** — 主張 → 理由 → 具体例・証拠 → CTA の例文を順に並べる。
13. **「上手な文章」より先に考えること** — 最初から難しい日本語を使う必要はない。まず 誰に伝える？ 何を伝える？ なぜ伝える？ 何をしてほしい？ を考え、決まってから文章を作る。
14. **デザインより先にライティングがある** — 例: Instagramの投稿。何を伝えるかが決まっていない状態でデザインを始めると、何の画像を使うか、どの文字を大きくするか、何を一番目立たせるかを決められない。先に伝える内容を決め、そのあとでどう見せるかを考える。ライティング → デザインの順番。
15. **AIが文章を書けるなら、ライティングを勉強する必要はない？** — AIは文章を書くことができる（例「Instagramの文章を作ってください。」ですぐ作れる）。しかしAIは最初から、誰に伝えるのか／何をしてほしいのか／何が一番大切なのか を知っているわけではない。
16. **AI時代に人間が考えること** — AIに文章を作ってもらう前に人間が決める: ① 誰に伝える？ ② どんな行動をしてほしい？ ③ 何を一番伝えたい？ ④ なぜそう言える？ ⑤ 具体例や証拠は？ ⑥ 最後に何をしてほしい？ ここまで決めれば、AIは文章を作る手伝いができる。
17. **AIに文章を書かせる例** — 「Instagramの投稿文を作ってください」＋ 読む人: 高校生／目的: オープンキャンパスに参加してもらう／主張: プログラミング未経験でもAIでアプリを作れる／理由: 日本語でAIに指示できる／具体例: 実際に未経験の学生もアプリ制作をしている／CTA: プロフィールのリンクから申し込んでもらう／やさしい日本語で書いてください。
18. **AIに任せる部分と、人間が決める部分** — 人間: 誰に伝える？ 何をしてほしい？ 何を伝える？ 何を一番大切にする？ → AI: 文章を作る／短くする／言い方を変える／SNS用にする／メール用にする／Webサイト用にする。
19. **ライティングは文章だけに使うものではない** — 骨子を作る力はいろいろな場所で使える: Instagram／Webサイト／広告／メール／プレゼン／面接／商品説明／動画／AIへの指示。媒体が変わっても「誰に、何を、どの順番で伝えるか」という基本は同じ。
20. **今日一番覚えること** — マーケティング: 誰の行動を、どのように変えたいかを考える → ライティング: その目的に合わせて伝える内容・順番・言葉を設計し文章にする → 基本の骨子: 主張 → 理由 → 具体例・証拠 → CTA → デザイン: どう見せれば伝わるかを考える → 発信: 相手に届ける → 効果測定: 本当に行動が変わったか確認する。
21. **マーケティングの流れ** — 誰に？ → どんな行動をしてほしい？ → 何を伝える？ → どう伝える？ → どこで伝える？ → 伝える → 行動は変わった？
22. **今日のまとめ** — マーケティングは、人に行動してもらうために考えること。しかし考えただけでは相手には伝わらない。その考えを相手に伝わるメッセージにするためにライティングがある。だから、マーケティングにはライティングが必要。
