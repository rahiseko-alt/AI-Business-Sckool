# NotebookLM（現 Gemini Notebook）の教育利用

## 事実（公式ページより）

### 名称変更
- **2026年7月16日、NotebookLM は「Gemini Notebook」に名称変更**（Google 公式ブログ）。独立したプロダクトのまま、Google エコシステム全体と連携を強化。既存の共有リンクは自動リダイレクト。
- 同時発表: 各ノートブックに安全なクラウド環境が付き、コードを実行してソースに基づくデータ分析が可能（まず AI Ultra と Workspace 顧客、Pro ユーザーへ順次）。Gemini アプリとのクロスアプリ同期。
- ブログ記載の公式ドメイン: notebooklm.google。【曖昧】教育ページでは「notebook.google.com」とも読める記載があったが要約ツール経由のため未確定
- 利用規模: 3,000万人以上、60万以上の組織

### 教育向け概要
| 項目 | 内容 |
|---|---|
| 費用 | Workspace for Education Fundamentals の対象校は無料。上位は Google AI Pro for Education |
| 年齢（学校アカウント） | Workspace for Education では**全年齢**が利用可（管理者が有効化した場合）。コアサービス扱い（Gmail、カレンダー、ドキュメントと同等） |
| 年齢（個人アカウント） | 13歳以上（または国の最低年齢）。Google アカウントでの年齢確認が必要 |
| 18歳未満 | より厳しいコンテンツポリシー、追加のガードレール（2025年8月4日から若年ユーザーへ提供） |
| データ保護 | チャットとアップロードしたソースは人間のレビュー対象外、AI モデルの学習に不使用（学校・エンタープライズ）。COPPA・FERPA 準拠をサポート |
| 言語 | UI と AI 出力は50以上の言語、ソース処理と音声/動画解説は80以上の言語。ヘルプの言語一覧に日本語あり |
| 地域 | 200以上の国と地域（教育ページ）／Gemini アプリ提供の180以上の地域（FAQ） |
| アクセス | Web とモバイルアプリ（Android / iOS） |

### 授業で使える機能（教育ページ記載）
- 音声解説（Audio Overviews: ポッドキャスト風要約、多言語）
- 動画解説（Video Overviews）
- マインドマップ
- フラッシュカード、クイズ
- 学習ガイド、レポート
- ガイド付き学習（Guided Learning）モード
- インフォグラフィック、スライド
- 引用付きチャット（回答はアップロードしたソースに基づく）
- 2025年4月3日追加: 学習用ソースの発見（Discover）、PDF の画像・グラフ理解強化

### 利用上限（ヘルプ「Upgrade」ページ）

| 項目 | Standard（無料） | Plus | Pro | Ultra |
|---|---|---|---|---|
| ノートブック数 | 100 | 200 | 500 | 500 |
| 1ノートブックのソース数 | 50 | 100 | 300 | 500〜600 |
| チャット/日 | 50 | 200 | 500 | 2,500〜5,000 |
| 音声解説/日 | 3 | 6 | 20 | 100〜200 |
| 動画解説/日 | 3 | 6 | 20 | 100〜200 |
| レポート・フラッシュカード・クイズ/日 | 各10 | 各20 | 各100 | 各500〜1,000 |

- 1ソースあたり50万語、ローカルアップロードは最大200MB（FAQ）
- 対象の Workspace / Workspace for Education ライセンスで上位枠を利用可能な場合あり。【曖昧】Education Fundamentals がどの枠に当たるかは取得ページで明示なし

## まとめ（筆者による整理・提案）

- **3科目すべてで最も使いやすいツール**。「ソースに基づいて答える」性質が、ハルシネーション対策の教材として優れている。
- 無料枠の「音声解説 3回/日」「動画解説 3回/日」は、1人が1コマで何度も作ると足りなくなる可能性あり。授業では「班で1つ」「作るのは1回」などの運用ルールを決める。
- スマホアプリで PDF・Web ページ・Google ドライブの資料を読み込ませられるので、Google ドライブと組み合わせた演習に向く。
- 名称変更直後のため、学生の画面表示が「NotebookLM」「Gemini Notebook」どちらでも混乱しないよう、授業資料には両方の名前を書く。

### 科目別の使い方
- **マーケティング**: 競合企業の公開資料・記事をソースにして比較表や SWOT を作る／音声解説で「業界ニュースポッドキャスト」を作る
- **AI演習（実践）**: 同じ質問を Gemini アプリと Gemini Notebook に投げ、ソースの有無で回答がどう変わるかを比較
- **ビジネス情報リテラシー**: 引用元を確認する習慣、アップロードしてよい情報・いけない情報（個人情報・社外秘）の判断

### 授業3〜4回分の例
1. ノートブック作成、ソース追加（ドライブ・URL・PDF）、引用付きチャット
2. マインドマップと学習ガイドで内容を構造化
3. フラッシュカード・クイズで相互テスト
4. 音声解説/動画解説を作り、内容の正確性を班で検証
