# Google Skills（旧 Google Cloud Skills Boost）生成 AI 学習パス

## 事実（公式ページより）

- Google Cloud Skills Boost の学習コンテンツは現在 **Google Skills（www.skills.google）** で提供。資格の種類は Certificates／Skill Badges／Certifications（監督付き試験）の3つ。
- 無料枠: GEAR プログラム会員は月35クレジット（Google Skills トップ）。2024年10月の Google Cloud ブログでは Google Cloud Innovators 会員に月35クレジット（学習パス約1本/月分）と記載。

1. 生成 AI の概要（45分、入門）— 生成 AI の概要、利用方法、従来の ML との違い、生成 AI アプリ開発用の Google ツール

### その他の学習パス（2024年10月16日 Google Cloud ブログ）
開発者・データ・ML エンジニア向けの4パス（Build and Modernize Applications with Generative AI 等）。専門学校の3科目には技術的に過剰。

## まとめ（筆者による整理・提案）

- 「生成 AI の概要」パスのうち **コース1・2（計75分）は日本語タイトルの短時間入門コース**なので、AI演習（実践）の第1〜2回の予習動画として使える。コース3・4は Google Cloud コンソール操作を含むため PC 前提。
- 入門レベル・短時間で、専門学校の学生層に合う。
- Generative AI Leader は難度が高いが、「AI をビジネスにどう使うか」の視点はマーケティング授業の後半（AI 活用戦略）の参考になる。
