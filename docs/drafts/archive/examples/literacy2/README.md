# 具体例: リテラシー成果物② 週28時間 勤務時間管理表（上限10点）

作成日: 2026-09-28。状態: 見本（未承認）。数字はすべて python で計算して確かめた。

## 1. 学生に配るもの

### 課題文
> あなたは店の事務担当です。店長から「留学生スタッフが週28時間を超えないように、スマホで勤務を入れたら、超えそうなときに分かる表を作って」と頼まれました。
> 表は AI に作らせてかまいません。ただし、下の「入力の約束」を必ず守ってください。
> 採点では、教員があなたの表に**教員だけが持っているテスト用の勤務データ**を入れて、正しく動くかを確かめます。

### 入力の約束（全員共通。これが採点の差し込み口になる）
- シート名「入力」の A〜E 列に、1行1勤務で入れる: 日付／開始／終了／休憩(分)／勤務先
- シート名「結果」の B1 に「総勤務時間」、B2 に「どの7日間でも最大の合計」、B3 に「28時間を超えた7日間があれば その最初の日」、B4 に「入力ミスの行数」を出す
- 教員（テスト用アカウント）を編集者として共有する

### 練習データ（学生ごとに違う）
- `practice-07.csv` は出席番号07の学生の分。2026年11月の18勤務。番号ごとに日時・休憩・勤務先を変えて配る
- 07番の正解: 総勤務時間 **66.0時間**（教員だけが持つ）

### 正解（答え合わせ表）
| 出力 | 正解 | よくある間違い |
| --- | --- | --- |
| B1 総勤務時間（入力ミス行を除く） | **39.0** | 休憩を引かない 40.0／日付またぎで −20 時間になる |
| 月〜日で区切った週の合計 | 1/11週 27.0、1/18週 12.0 | （参考。どちらも28以下） |
| B2 どの7日間でも最大 | **29.0**（1/13〜1/19） | 月〜日の固定週だと 27.0 で「超えていない」と出る＝罠4 |
| B3 超えた7日間の最初の日 | **1/13** | 空欄（固定週で作った表） |
| B4 入力ミスの行数 | **1** | 0（ミスを見逃す） |

罠4 が一番重い。入管の説明は「どの曜日から数えても1週28時間以内」なので、月〜日の固定週で作った表は、実際には違反している働き方を「問題なし」と表示する。
「28時間の表を作って」と AI に頼むと、ふつうは月〜日の週ごとの合計を作る。**AI に丸投げした表は罠4で必ず落ちる**。
（入管の説明の該当ページは、授業で使う資料セットに教員が固定して入れる【曖昧】: まだ一次情報で確認していない）

## 3. 段と判定（10点＝基礎4＋6段、すべて○か✖）

| 段 | 点 | 判定（教員が見るもの） | かかる時間 |
| --- | --- | --- | --- |
| 基礎 | 4 | 提出フォームにリンクがあり、教員が開けて「入力」「結果」シートがある | 10秒 |
| 1 | 5 | 自分の練習データで B1 が正解（07番なら 66.0）と一致 | 10秒 |
| 2 | 6 | 隠しデータを貼った後、休憩を引いている（B1 が 40.0 でない） | 貼り付け30秒＋5秒 |

| 5 | 9 | B2＝29.0、B3＝1/13（どの7日間でも判定できている） | 5秒 |
| 6 | 10 | B4＝1（入力ミスを見つけている） | 5秒 |

1人あたり約1分半。30人で45分。

## 4. 悪いシナリオへの答え

| シナリオ | この課題ではどうなるか |
| --- | --- |
| 課題文を AI に貼って出すだけ | 基礎〜段3くらいまで。固定週で作るので段5で止まる。入力ミス検出（段6）も普通は付かない |
| 級友の表をコピー | 練習データが番号ごとに違うので段1が合わない。ただし隠しテストの段は通る【弱点】→ 変更履歴で作った人を確かめる |
| 正解が学生に見える | 隠しデータは提出後に教員が貼るだけ。学生には渡さない。毎年変える |
| 正解が複数ある | 出力のセル番地と形式を約束で決めているので、正解は1つ |
| 実データの提出 | 練習データも隠しデータも架空。本人の勤務は一切入れさせない |
| 前の成果物が未提出 | この課題は単独で作れる |
| スマホでできない | 表の作成・貼り付けはスマホの Sheets でできる【曖昧: 最終確認は要】。教員の貼り付けはPCでよい |

## 5. 残る弱点
- 隠しテストが全員同じなので、表そのものを丸ごとコピーすると段2〜6は通る。変更履歴で防ぐが、完全ではない
- 日付をまたいだ勤務を「始めた日」に数えるか、日ごとに分けるかは、入管の考え方を確認して正解を固定する必要がある【曖昧】
