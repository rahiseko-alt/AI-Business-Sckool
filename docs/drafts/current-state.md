# 現在地の整理（2026-09-28）

呼び方: 利用者を「先生」と呼ばない。

この1枚を、決定事項の正とする。細部の出典は各ファイル。古い記録と食い違う場合はこちらが優先。

## 1. 対象

- 小齊平の後期3科目。マーケティング16回・AI演習（実践）18回・ビジネス情報リテラシー19回。1回100分
- キャリア形成演習は対象外
- 提出先: スプレッドシートの「シラバス」シートをひな形として3枚コピーし、1科目1枚で埋める
- 総授業時間は後期の実時間（回数×100分）。単位数は2単位【曖昧】（学校未確認。2026年4月から1単位＝45時間の学修）

## 2. 思想（`docs/knowledge/history/philosophy.md`）

- 最上位: AIビジネス能力。自分の役に立つ → 他人の役に立ち「ありがとう」
- 報酬を得ること・外部からの受託は禁止（教員方針の「報酬」段階は授業で実行しない。扱いは未定）
- 3科目の役割: マーケティング＝商談力、AI演習＝実装力、リテラシー＝運用力。前工程の内容が後工程の採点項目になる
- 必須ツール: Gemini Notebook・スプレッドシート・ドキュメント・スライド・画像生成・フォーム・ドライブ・Meet・カレンダー・Gmail（動画編集は外した。Meet・カレンダー・Gmail は2026-09-28追加）
- 学生は個人の Google アカウントを使う
- 学生は全員成人（利用者、2026-09-28）。年齢条件（画像編集18歳以上など）は問題にならない
- スマホ完結。1つ1つが成果物として成立。らせん型（前に覚えたものに新しい知識を足し、課題ごとに難しくなる）
- 月に合わせて区切らない。学校で実際に使う課題は案の一つにすぎない。学校指定教科書は参考書
- 一本線: 上の思想から各回の授業まで線でつなぐ。未定は未定、断絶は断絶と書く
- 採点の重心は上の層。救済は単位ぎりぎり（補習をなくすため）まで

## 3. 評価（`docs/drafts/rubric-v1.md`）

- 100点＝成果物80点（1科目5個、学習成果）＋小テスト20点（学習姿勢の態度点）
- 期末試験は必須ではない
- 成果物の段: 基礎4、以降 +1×7、+2×3、+3×3、+4。全15段、累計30点
- 成果物ごとの上限: 5・10・15・20・30（計80）
- 小テスト: 毎回、満点まで再提出できる。満点なら○。点数＝20×○の回数÷授業回数。欠席は✖
- 出席率70%未満は卒業できない。70%を最低ラインとして計算
- 小テストの端数: 小数第2位を四捨五入し、小数第1位まで（14.98→15.0、14.32→14.3、16.25→16.3）
- 合計点の端数: 切り捨て（学校共通のルール、変更不可）【曖昧】（利用者の「切り捨てルールは学校共通」を合計点の扱いと解釈）。例: 成果物46＋小テスト14.4＝60.4 → 60点（D）
- 小テストは授業中しか受け付けないため、出席だけを評価していることにはならない（利用者判断）
- 救済ライン: 出席70%の学生がDに届く成果物の点。AI演習・リテラシーは46点、マーケティングは45点
- 評価項目の数: 小テストは評価項目に数えない（利用者）ので、成果物5個＝5項目で学校の「最大5つほど」に収まる
- スマホを忘れた・充電切れ（教員方針の減点）: 小テストを受けられないので、その回は✖になる形で反映する（指揮役の判断）
- 評定: A 90〜、B 80〜、C 70〜、D 60〜、E 59以下（学校規程）
