# 成果物15個 案 v4（指揮役、2026-09-28）— 利用者により却下（「v4もだめ」）

方針:
- 1つ1つが、それ単体で完結する実務（ツール操作の確認ではない）
- 科目の中で、成果物ごとに**場面とツールの組み合わせを変える**（同じ課題の繰り返しにしない）。前の成果物で覚えたツールを次で使い、新しいツールを足す
- 全課題で、教員が材料と正解を持ち、罠を仕込む。提出は教員のアカウントに届く形
- 最終課題（成果物5）は、それまでのツールを組み合わせて時間内にやり切る
- 共通の階段（`tool-map-and-ladder.md`）は仮説。各課題に当てて合わない所を洗い出す
