# リテラシー最終課題（成果物5、上限30点）: 講座運用の引き継ぎ40分

作成日: 2026-09-28。状態: 案（未承認）。数字はすべて `make_version.py` で作り、別の書き方の `verify.py` で検算した（40版すべて一致）。

## 100点の人（この課題で30点）は何ができるか

引き継いだばかりの運用ルール・申込データ・前任者の下書きから、AIを使いつつ自分で確かめて、ルールどおりの人数と費用を出し、誤りだけを過不足なく直した「そのまま送れるメール」を、安全な共有設定で、30分以内に一人で仕上げられる。

## 1. 形

- 授業中に一人で、制限時間40分。AIは使ってよい。スマホだけで行う（Sheets・ドキュメント・ドライブ・フォーム・画面録画）
- 場面は架空の学内講座（報酬・受託なし）。申込者は全員架空で、メールは `example.com`（実在しない予約ドメイン）。本人や他人の実データは一切扱わない
- 正しさの基準は、材料に書いた運用ルール（R1〜R15と改定）だけ。AIの一般論やネットの情報は基準にしない

## 4. 本人がやった証拠

- **合言葉**: 開始時に教員が黒板に書く語を、録画に映る形で「入力」シートA1に入れる（事前に作ったファイルは使えない）
- **画面録画**: 開始から提出フォームの送信画面まで止めない。教員は冒頭・最後・途中1か所だけ見る
- **版の履歴**: シートの最初の編集が開始時刻より後で、編集者が本人のアカウントだけ
- **時間**: 提出フォームのタイムスタンプ − 開始時刻。基礎と段1が○の場合、40分を超えた分、1分（切り上げ）ごとに合計点（基礎を含む）から1点を引く（0点が下限）

## 6. AIに丸投げした学生は何点になるか（見込み）

課題文・ルール・CSVをAIに貼って答えを写すだけの場合、基礎・段1・段2は本人の操作なので取れる（6点）。段4〜6（ルールを読めば分かる誤り）はAIでも取れることが多い（＋3点）。B4（段8a）も合いやすい（＋1点）。一方、35行を目で数えると大文字・空白・大文字のキャンセル・17:02のどれかで数がずれるので、数に依存する段3・7・8b・9a・9b・10・11a・11b は✖になりやすい。AIは行03の「！」などを直したがるので段12、全文を書き直すので段13も✖になりやすい。ここまでで**約10点**。独立採点なので、30分以内に出せば段14の4点がそのまま加わり**約14点**になる。ルールを渡して検算させ、差分を自分で確かめた学生だけが数の段と段12・13を取れる。実地検証（`sim-result.md`）の丸投げも、結果シート・訂正シートで取れたのは段4〜6・8aの4点だけだった。【曖昧】実際のGeminiで07番を解かせる試しはまだしていない。本番前に一度やる。

## 7. コピーした学生はどうなるか

- 他人の番号のシートを出す: ファイル名が自分の番号でなければ基礎が✖、名前を変えても版の履歴に他人の編集が残るので段1が✖。どちらでも前提条件を満たさず**0点**
- 答えだけ聞き写す: B1・B2（どの版も2）と、行09・10・12・14・15の直しは全員同じなので段3・4・5が取れ、訂正する行も写せば誤検出がなく段12も取れる。日付・定員・人数は版で違うので段6・7・8b・9a・9b・10・11a・11b・13は✖（B4は定員の数なので、偶然同じ定員の版なら段8aの1点が入る）。基礎・段1・段2と合わせて**12点**（偶然一致で13点）、30分以内なら段14の4点が加わり**16点**前後

## 8. 残る弱点

- 別の端末（2台目のスマホ）で人に聞いても、画面録画には映らない。AI利用は許しているので、防げるのは「他人のファイルを出す」ことだけ
- B1・B2 と、ルールで決まる直し（行09・10・12・14・15）は全版共通。写しで段3・4・5・12（6点）が取れる。独立採点なので、写した学生も段14（30分以内、4点）を取れる
- 40分の画面録画はファイルが大きい（数百MB〜1GB超）。学内Wi-Fiで10分以内に上がるか【曖昧】実機で確認する。上がらない学生は版の履歴だけで段1を判定する案も要る
- スマホの Sheets アプリで CSV を取り込めるか【曖昧】実機で確認する。駄目なら教員が番号版をスプレッドシートにして、本人だけに共有してコピーさせる
- 段2の「共有相手が教員だけ」は、閲覧者の教員からは完全には見えない（見えるのは一般公開でないことと、自分が閲覧者であることまで）

- 第1回が必ず定員超えになるので、B4は「定員の数」と同じ。段8a はほぼ全員○で、差は段8b（B5）で付く
