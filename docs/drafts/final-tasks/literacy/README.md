# リテラシー最終課題（成果物5、上限30点）: 講座運用の引き継ぎ40分

作成日: 2026-09-28。状態: 案（未承認）。数字はすべて `make_version.py` で作り、別の書き方の `verify.py` で検算した（40版すべて一致）。

## 100点の人（この課題で30点）は何ができるか

引き継いだばかりの運用ルール・申込データ・前任者の下書きから、AIを使いつつ自分で確かめて、ルールどおりの人数と費用を出し、誤りだけを過不足なく直した「そのまま送れるメール」を、安全な共有設定で、30分以内に一人で仕上げられる。

## 1. 形

- 授業中に一人で、制限時間40分。AIは使ってよい。スマホだけで行う（Sheets・ドキュメント・ドライブ・フォーム・画面録画）
- 場面は架空の学内講座（報酬・受託なし）。申込者は全員架空で、メールは `example.com`（実在しない予約ドメイン）。本人や他人の実データは一切扱わない
- 正しさの基準は、材料に書いた運用ルール（R1〜R15と改定）だけ。AIの一般論やネットの情報は基準にしない

## 4. 本人がやった証拠

- **合言葉**: 開始時に教員が黒板に書く語を、録画に映る形で「入力」シートA1に入れる（事前に作ったファイルは使えない）
- **画面録画**: 開始から提出フォームの送信画面まで止めない。教員は冒頭・最後・途中1か所だけ見る
- **版の履歴**: シートの最初の編集が開始時刻より後で、編集者が本人のアカウントだけ
- **時間**: 提出フォームのタイムスタンプ − 開始時刻。40分を超えたら、超過1分（切り上げ）ごとに到達段から1段下げる（基礎より下には下げない）

## 6. AIに丸投げした学生は何段で止まるか

課題文・ルール・CSVをAIに貼って答えを写すだけの場合、段1・2は本人の操作なので通る。段3〜6（ルールを読めば分かる誤り）はAIでも取れることが多い。段7で止まる見込みが高い（35行を目で数えると、大文字・空白・大文字のキャンセル・17:02のどれかで数がずれる）。**7〜10点**。仮に数が合っても、AIは行03の「！」などを直したがるので段12、全文を書き直すので段13で止まる。ルールを渡して検算させ、差分を自分で確かめた学生だけが上まで行く。【曖昧】実際のGeminiで07番を解かせる試しはまだしていない。本番前に一度やる。

## 7. コピーした学生はどうなるか

- 他人の番号のシートを出す: ファイル名・日付・定員が自分の材料と合わず、段3以降の数字（特にB7は40版すべて違う）が✖。録画と版の履歴にも受け取りが残る
- 答えだけ聞き写す: B1・B2（どの版も2）と、行09・10・12・14・15の直しは全員同じなので段5まで届く。段6（日付が版で違う）か段7で止まる。**9〜10点**

## 8. 残る弱点

- 別の端末（2台目のスマホ）で人に聞いても、画面録画には映らない。AI利用は許しているので、防げるのは「他人のファイルを出す」ことだけ
- B1・B2 と、ルールで決まる直し（行09・10・12・14・15）は全版共通。写しで段5まで行ける
- 40分の画面録画はファイルが大きい（数百MB〜1GB超）。学内Wi-Fiで10分以内に上がるか【曖昧】実機で確認する。上がらない学生は版の履歴だけで段1を判定する案も要る
