## 一連の仕事と、15点の人

- 調査（9問・9形式）→ 除外4種 → **ターゲットだけで数える** → **Googleマップの競合を避けて時間を決める** → 苦手・満足度 → 表紙を3回＋Canva で5ページ → MP4 で提出
- 成果物2より増えたもの: 形式6→9（表2種・星）、行数約27→約42、除外2→4種、ターゲットの絞り込み、「いいえ」の人の星、Googleマップの競合（評価と口コミの件数）、5ページの型、表紙の再現（3回）、合言葉と作業録画
- **15点の人は**: ターゲットを絞って汚れたデータを正しく数え、口コミの件数まで見て競合を避け、5ページすべてを数字どおりに作り、同じ指示文で3回作った表紙が3枚とも文字と数字どおりになる

## 罠

| 罠 | 起きること |
| --- | --- |
| テスト送信2・締切後2・重複3人・日本出身2〜3人 | 数えると B1・B2 がずれる（40版すべて B2 が変わる） |
| ターゲットだけで数える | 全員で数えると苦手も時間も変わる（40版すべて） |
| 「いいえ」の人も星を付けている | 満足度に混ぜると低く出る（40版すべて） |
| 表の複数回答は「昼, 夜」とカンマ区切り | 完全一致で数えると少なく出る |
| 競合（マップの写し） | 競合を見ないと20版で時間がずれる。★4.9 でも口コミ3件の教室を強いとすると40版すべてでずれる。★4.0・20件（ちょうど）を外すと10版でずれる |
| Canva | 王冠マークの素材（無料版は透かし）、テンプレートの見本文字 |
| 画像の文字 | 何もしないと、漢字の崩れ・「%」の抜け・英語の飾り文字・別の数字が入る。3回のうち1回だけ崩れることが多い |

## 番号版・丸投げ・コピー・弱点

- 苦手（4種）と時間（4マス、答えは平日昼か土日夜が20版ずつ）を番号で回し、人数は乱数。40版の正解の組はすべて違う
- 丸投げ: フォーム・表紙・Canva は本人の手が要る。数えさせると除外かターゲットの絞り込みで段2〜5で止まる見込み【未検証】
- コピー: 他人の数字は段2で落ちる。表紙の3回は指示文を写せても、中の文字と数字が番号ごとに違う
- 【曖昧】マップの写しは架空。練習の回では実際にマップで評価と口コミ件数を見る（マップのアプリは両OSで使える）。実在の店の評価を課題の正解にしない（変わるため）
- 【曖昧】Gemini 無料版の1日の生成回数の上限（数値の記載なし）。3回＋作り直しで足りるか事前に試す
