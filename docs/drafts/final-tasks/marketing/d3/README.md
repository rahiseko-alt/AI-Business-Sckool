## 番号版・丸投げ・コピー・弱点

- 苦手（4種）と時間（4マス）を番号で回し、人数は乱数。40版の正解の組はすべて違う
- 丸投げ: フォーム・表紙・スライドは本人の手が要る。数えさせると除外かターゲットの絞り込みで段2〜5で止まる見込み【未検証】
- コピー: 他人の数字は段2で落ちる。表紙の3回は指示文を写せても、中の文字と数字が番号ごとに違う
- 【曖昧】Gemini 無料版の1日の生成回数の上限（数値の記載なし）。3回＋作り直しで足りるか事前に試す
