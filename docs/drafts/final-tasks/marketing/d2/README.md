## 一連の仕事と、10点の人

- 調査（6問・6形式）→ 数える（テスト送信と重複を除く、割合を丸める）→ 相手と困りごとを決める → 表紙画像＋2ページ（Canva）→ MP4 で提出
- 成果物1より増えたもの: 形式が3→6、行数が約15→約27、罠が1→3（重複・割合の丸め）、枚数が2→3、表紙の画像生成、Canva（王冠素材・見本文字）、締切の計算
- **10点の人は**: 6問のアンケートを正しい形式で作り、テスト送信と重複を除いて数え、割合を正しく丸め、指定の文字どおりの表紙と、透かしも見本文字もない3ページのカルーセルを50分で提出できる

## 罠

| 罠 | 起きること |
| --- | --- |
| テスト送信2行（正解とは別の相手・困りごとを選んでいる） | 数えると B1 が増え、相手か困りごとが入れ替わる |
| 重複2人（古い行は別の相手・困りごと） | 同上。40版中29版で相手が、11版で困りごとが入れ替わる（テストと重複を両方数えた場合） |
| 割合の丸め | 掃除しないと割合も変わる（40版すべて） |
| 締切は開催日の3日前 | 曜日のずれ |
| 画像生成の文字 | 何もしないと漢字の崩れ・英語の飾り文字・余計な文字が入る |
| Canva | 王冠マークの素材は無料版で透かしが入る。テンプレートの見本文字が残る |

## 段と判定（基礎＋独立採点。すべて○✖）

基礎が✖なら0点。基礎が○なら、そこから先の段は互いに独立に判定し、○になった段の点を合計する。段2（B1）は重複・テスト送信を見分ける、この課題でいちばんの罠なので、基礎の点を4→3に下げたぶんを段2にまわし2点にした（合計は変えていない）。

| 段 | 点 | ○の条件（1行） | 見る時間 |
| --- | --- | --- | --- |
| 基礎 | 3 | 50分以内に提出され、3つのリンクが開け、MP4 に3ページが順に映り、透かし・見本文字・禁止語がない | 60秒 |
| 1 | 1 | フォームの6問の形式が 記述式・プルダウン・ラジオボタン・チェックボックス・均等目盛・段落 | 20秒 |
| 2 | 2 | B1（テスト送信と重複を除いた人数）が正解 | 8秒 |
| 3 | 1 | 表紙の B2・B3 が正解で、画像内の文字が指定の2行どおり（誤字・余計な文字なし） | 15秒 |
| 4 | 1 | 2枚目の B1・B4・B3 が正解 | 10秒 |
| 5 | 1 | 2枚目の B5・B6 が正解 | 10秒 |
| 6 | 1 | 3枚目の日時・締切（奇数 12月2日（水）／偶数 12月3日（木））・申込方法が正解 | 10秒 |

段は互いに独立の基準。例えば段2（B1）が✖でも、段3〜6の出来はそれぞれ別に判定し、○になった分の点は入る。

採点時間: 1人約2.5分、40人で約1.5時間。

## 番号版・丸投げ・コピー・弱点

- 相手（4種）と困りごと（5種）を番号で回し、人数は乱数。40版の正解の組はすべて違う
- 丸投げ: フォームは本人が作るので基礎・段1は独立に届く。表紙の画像生成も本人の操作が要るが、段3は B2・B3（相手・困りごと）の正しさも含むため、数えさせて重複の扱いを誤ると段3・段2・段4〜6が✖になりやすい見込み【未検証】
- コピー: 他人の数字を写すと、データに依存する段2〜6がすべて✖になる。段1（フォーム形式）だけは、正解と同じ形式で作れていれば独立に通る
- 【曖昧】Gemini 無料版で日本語の文字入り画像が何回で指定どおりになるか。教員が事前に試すこと
