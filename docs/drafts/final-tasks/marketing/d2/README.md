## 段と判定（基礎＋独立採点。すべて○✖）

基礎が✖なら0点。基礎が○なら、そこから先の段は互いに独立に判定し、○になった段の点を合計する。基礎の点は4のまま変えていない（利用者の指示: 基礎の配点はエージェントが勝手に変えてよいものではない）。

（2026-09-29改訂3）上限を8・12・15・20・25に変更（利用者決定）。増えた2点は、満点の形から「何が欠けると何点失うか」を引き算で見直し、1段に束ねていた別々の観点を分けて配った。段3（旧: 表紙の B2・B3 の正しさ＋画像の文字どおり）は、集計の正しさと画像生成の出来という別の対象なので3a・3bに分けた。段6（旧: 3枚目の日時・締切・申込方法）は、写すだけの日時・申込方法と、3日前を数える締切（罠）が別なので6a・6bに分けた。課題・罠・正解は変えていない。

採点時間: 1人約2.5分、40人で約1.5時間。

## 番号版・丸投げ・コピー・弱点

- 相手（4種）と困りごと（5種）を番号で回し、人数は乱数。40版の正解の組はすべて違う
- 丸投げ: フォームは本人が作るので基礎・段1は独立に届く。表紙の画像の文字（段3b）も本人の操作で独立に取れる。数えさせて重複の扱いを誤ると段2・3a・4・5が✖になりやすく、基礎＋段1・3b・6a・6bの8点前後の見込み【未検証】
- コピー: 他人の数字を写すと、データに依存する段2・3a・4・5が✖になる。段1（フォーム形式）・3b（画像の文字が自分のシートどおり）・6a（日時・申込方法）・6b（締切）は、自分で正しく作れていれば独立に通る。日時と締切は番号の奇数・偶数で違うので、偶奇の違う人の3枚目を丸写しすると6a・6bも✖になる
- 【曖昧】Gemini 無料版で日本語の文字入り画像が何回で指定どおりになるか。教員が事前に試すこと
