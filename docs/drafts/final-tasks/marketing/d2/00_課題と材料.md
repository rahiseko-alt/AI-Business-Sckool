# マーケティング 成果物2 課題と材料（学生に配る）

成果物2（12点）。**授業中に一人で、50分**。AI（Gemini など）、Canva（無料版）、画像生成・画像編集を使ってかまいません。

## 依頼

みなと日本語カフェ（架空）が「電話の日本語練習会」を開きます。スタッフから頼まれました。

> 電話で困っている留学生に来てほしい。アンケートで「誰との電話で、何に困っているか」を調べて、その数字で3ページのカルーセルを作って。

回答は、教員が渡す **あなたの番号の回答データ** を使います。実際のSNSには投稿しません。

## 手順と提出

1. **Google フォーム**で、材料Aの6問のアンケートを作る
2. 回答データの**コピーを作成**し、シート「企画」に B1〜B6 と B7（表紙の指示文）を書く
3. **Gemini** で1ページ目の表紙画像を作る（材料C）
4. **Canva** で「Instagram の投稿（正方形 1080×1080）」を新しく作り、表紙と2・3ページ目を入れて、**MP4動画**でダウンロードし、ドライブに上げる
5. フォーム・シートは教員を**編集者**に、動画は**閲覧者**で共有し、提出フォームに3つのリンクを送る（**50分**以内が目安。授業内で終える）

## 材料A 6問（答え方に合う形式を自分で選ぶ）

| 番号 | 問題文 | 答え方 |
| --- | --- | --- |
| 1 | ニックネームを書いてください | 1行の文字 |
| 2 | 出身の国・地域を選んでください | 1つだけ: 日本／中国／韓国／台湾／ベトナム／ネパール／ミャンマー／インドネシア／フィリピン／タイ／スリランカ／モンゴル／ウズベキスタン／その他（14個。10個以上はリストから選ぶ形式） |
| 3 | 電話でいちばん困る相手を1つ選んでください | 1つだけ: アルバイト先／病院／学校／役所 |
| 4 | 電話で困ることをすべて選んでください | いくつでも: 聞き取れない／敬語が分からない／名前をうまく言えない／番号を聞き返せない／緊張する |
| 5 | 電話で話す自信はどのくらいですか | 数字の目盛 1〜5（1＝自信がない、5＝自信がある） |
| 6 | 練習会でやってみたいことを自由に書いてください | 何行でも書ける文字 |

## 材料B 数え方（シート「企画」。B列に値だけ）

数えない行: メールアドレスが `cafe-staff@example.com`（テスト送信）。同じメールアドレスが2行以上あれば、**いちばん新しい行だけ**を数える。

| セル | 書くこと |
| --- | --- |
| B1 | 数える回答の人数 |
| B2 | 問3でいちばん多い相手 |
| B3 | 問4でいちばん多く選ばれた困りごと |
| B4 | B3を選んだ人数 |
| B5 | 問5で1か2と答えた人数 |
| B6 | B5 ÷ B1 × 100（小数第1位を四捨五入して整数） |
| B7 | 表紙を作ったときの Gemini への指示文（そのまま貼る） |

## 材料C 3ページのカルーセル（Canva）

| ページ | 必ず入れること |
| --- | --- |
| 1（表紙・画像生成） | 画像の中に「◯◯への電話」（B2）と「◯◯で困っていませんか？」（B3）の2行だけ。ほかの文字・英語・ロゴは入れない |
| 2 | 「◯人のうち◯人が『◯◯』」（B1・B4・B3）と「◯人（◯%）が電話の自信1か2」（B5・B6） |
| 3 | 練習会の日時、申込締切、申込はプロフィールのリンクから |

- 練習会: 番号が**奇数**の人は **12月5日（土）**、**偶数**の人は **12月6日（日）**。どちらも14:00〜15:30。申込締切は**開催日の3日前**
- 2・3ページ目の文字は Canva で打つ。数字はシート「企画」と材料にあるものだけ
- Canva: **王冠マークの素材（有料）を使わない**（無料版では透かしが入る）。テンプレートの見本の文字を残さない。1ページ3秒以上
- 使わない言葉: 必ず／絶対／一番／誰でも／今だけ
