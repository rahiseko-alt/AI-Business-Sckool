# 材料B 企画のルール（学生に配る）

企画は、このルールどおりに回答データから決めます。ルールと違う決め方をした企画は、どんなに良くても点になりません。

## 1. 回答データの扱い

- 自分の番号の回答データの**コピー**を使う。**並べ替えない・行を消さない**（除く行は、別の列や別のシートで印をつける）
- 行番号は、見出しを1行目とするスプレッドシートの行番号

## 2. 数えない回答（除外）

次のどれかに当てはまる行は、数えない。

1. メールアドレスが `cafe-staff@example.com` の行（運営のテスト送信）
2. タイムスタンプが **2026/11/30 23:59:59 より後**の行（締切後）
3. 同じメールアドレスが2行以上ある場合、**いちばん新しい1行だけ**を残し、古い行は数えない
4. 出身が「日本」の行（この調査の対象は留学生だけ）

残った回答を「**有効回答**」、有効回答のうち問2が「いいえ」の人を「**ターゲット**」と呼ぶ。

## 3. 数字から企画を決める

| 決めること | 決め方 |
| --- | --- |
| 伝える場面 | ターゲットの問5で「よく困る」の人数が**いちばん多い場面** |
| 割合 | その人数 ÷ ターゲットの人数 × 100。小数第1位を四捨五入して整数（%） |
| 新しい回の曜日・時間帯 | ターゲットの問6で選ばれた数が**いちばん多いマス**（平日・土曜・日曜 × 午前・午後・夜 の9マス） |
| 満足度 | 有効回答のうち問2が「**はい**」の人の問8の平均。小数第2位を四捨五入して小数第1位。空欄は数えない |
| 投稿先 | ターゲットの問4で選ばれた数がいちばん多いSNS。ただし、5枚の画像を1つの投稿にできる **Instagram・TikTok・Facebook** の中から選ぶ（X は1投稿4枚まで。LINE・YouTube は今回は投稿先にしない） |
| 投稿時間帯 | ターゲットの問10の「時」がいちばん多い時間帯（例: 21:35 → 21時台） |
| 最初の回 | 材料Dで、その曜日・時間帯が○の**いちばん早い日**。平日＝月〜金（**祝日を除く**） |
| 申込締切 | 最初の回の**3日前** |
| 申込方法 | プロフィールのリンクの申込フォーム。参加費は0円 |
