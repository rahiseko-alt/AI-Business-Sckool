# 材料C カルーセルの型（学生に配る）

カルーセル＝1つの投稿に何ページかの画像を入れ、横にめくって読ませる投稿。今回は **5ページ**。**Canva**（無料版）で作る。

## サイズ（投稿先 B6 で決まる）

| 投稿先 | Canva で作るサイズ |
| --- | --- |
| Instagram | 1080×1350（縦長） |
| TikTok | 1080×1920（縦に長い） |
| Facebook | 1080×1080（正方形） |

## 5ページの役割（この順番で）

| ページ | 役割 | 必ず入れること（シート「企画」のセル） |
| --- | --- | --- |
| 1 | 問いかけ（主張） | **表紙画像**（下の条件）を大きく貼る |
| 2 | データ | ターゲットの人数（B2）、よく困る人数（B4）、割合（B5）、場面（B3）。例の形: 「カフェに来たことがない留学生◯人のうち◯人（◯%）が、◯◯で『よく困る』」。あわせて、ターゲットの問5「よく困る」の人数を4つの場面で比べる**棒グラフ** |
| 3 | 理由 | 新しい回の曜日・時間帯（B8）と、それを選んだ人数（B9）。例の形: 「◯人が参加しやすいと答えた◯◯に、◯◯の会話を練習する回を開きます」 |
| 4 | 証拠 | 満足度（B10）と人数（B11）。例の形: 「参加した人の満足度 ★◯（◯人の平均）」 |
| 5 | 行動（CTA） | 最初の回の日時（B12）、申込締切（B13）、申込方法（プロフィールのリンクの申込フォーム）。右下に合言葉 |

言い回しは変えてよい。入れる数字と言葉は変えない。

## 表紙画像（Gemini で、同じ指示文で3回作る）

3回とも同じ指示文で作る（作り直し・画像編集で直してよい）。3枚とも、次の4つを満たすこと。指示文はシート「企画」の B16 に貼る。

1. **文字**: 「（B3）の日本語、困っていませんか？」が1字も違わずに入っている
2. **数字**: 「（B5）%」が入っていて、ほかの数字はない
3. **配色**: 背景は紺、文字は白、数字は黄色
4. **レイアウト**: 文字が上、数字が真ん中でいちばん大きい。指定以外の文字（英語・ロゴ・飾りの文字）がない

## 約束

- 数字は、シート「企画」の数字と材料にある数字（参加費0円など）だけ。材料にない数字・体験談・「◯◯さんの声」を作らない
- 棒グラフの数字（棒の長さ・ラベル）は、自分で数えた人数と同じにする
- 使わない言葉: **必ず／絶対／一番／誰でも／今だけ／No.1**（ひらがな・カタカナ・英語で書いても同じ）
- Canva: **王冠マークの素材（有料）を使わない**（無料版では透かしが入る）。テンプレートの見本の文字を残さない。実在の人の写真・会社やSNSのロゴを使わない
- 色・写真・イラストは、上の条件のほかは自由（採点しない）

## 投稿文（シート「企画」の B14）

- **150字以内**（空白・改行は数えない）。ハッシュタグは付けない
- 順番は **主張 → 理由 → 具体例・証拠 → CTA**（ライティングの授業の骨子）
- 中の数字・日付は、カルーセルと同じものにする

## カルーセル動画

Canva の「共有」→「ダウンロード」→ ファイルの種類「MP4動画」→ すべてのページ。1ページ3秒以上（Canva の初期設定のままでよい）。
