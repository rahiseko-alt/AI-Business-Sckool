# マーケティング 最終課題（学生に配る）

成果物5（30点）。**授業中に一人で、70分**。AI（Gemini など）は使ってかまいません。
正しいかどうかは、材料A〜Dと、あなたの番号の回答データだけで決まります。

## 依頼

みなと日本語カフェ（架空）は、留学生が日本語で話す練習をする無料の集まりです。
スタッフから頼まれました。

> まだカフェに来たことがない留学生に来てほしい。
> アンケートを作って、その結果から「誰に・何を・いつ・どこで」伝えるかを決めて、SNSに出す5枚の投稿（カルーセル）を作ってほしい。
> 好きな内容ではなく、**アンケートの数字で決めた内容**にしてください。

アンケートの回答は、すでに集まったことにします。教員が渡す **あなたの番号の回答データ** を使ってください。
（あなたのフォームに実際の回答を集める必要はありません。**実際のSNSには投稿しません**。）

## 使う材料

| 材料 | 中身 |
| --- | --- |
| A 調査票の設計書 | フォームに入れる12問 |
| B 企画のルール | 回答の数え方と、数字から企画を決める方法 |
| C カルーセルの型 | 5枚に何を書くか、投稿文の約束 |
| D 会場の予定 | 2027年1月に会場を使える日 |
| 回答データ | あなたの番号の分（例: 07番なら responses-07）。**他の番号で作ったものは採点しません** |

## 手順

1. 開始の合図と同時に、スマホの**画面録画**を始める（通知はおやすみモードで切る）。黒板の「**合言葉**」を、録画の最初に映るようにメモアプリに打つ
2. **Google フォーム**で、材料Aの12問のアンケートを作る
3. 自分の番号の回答データの**コピーを作成**し、ファイル名を「マーケ最終_番号_氏名」にする。シート「企画」を足し、材料Bの B1〜B16 を埋める（集計のためのシートは自由に足してよい）
4. **Google スライド**で、材料Cの型どおりに5枚のカルーセルを作る。5枚目の右下に合言葉を入れる
5. 作業の画面録画を止める。次に、スライドを再生して1枚ずつ送る様子を**新しく画面録画**する（これが「カルーセル動画」。1枚3秒以上、全体30秒以内）
6. フォーム・スプレッドシート・スライドは、教員のアカウントを**編集者**に追加する。2本の動画はGoogle ドライブに上げ、教員のアカウントに**閲覧者**で共有する
7. 提出フォームに4つのリンク（フォーム・スプレッドシート・カルーセル動画・作業録画）を入れて送る
   - 作業録画が大きくて授業中に上げ終わらないときは、その欄に「後で」と書いて送り、**当日23:59まで**に提出フォームをもう一度送る

## 時間

- 開始の合図から**70分**以内に提出フォームを送る。70分を過ぎると、1分ごとに1段下がります
- 採点は、70分の時点の版で行います（Google の「版の履歴」で見ます）。70分より後の書き直しは点になりません

## してはいけないこと

- 他の人と相談する、ファイルを共有し合う（録画と共有の記録で分かります）
- 実際のSNSに投稿する、実在の人の名前や写真を使う
- 画像生成で文字や数字を作る（崩れるため）。文字と数字は、スライドに文字として打つ
