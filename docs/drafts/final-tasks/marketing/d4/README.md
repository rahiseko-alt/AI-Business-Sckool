- **20点の人は**: 3種類のデータ（アンケート・トレンド・アクセス）をそれぞれの決まりどおりに読み、5ページと投稿文を数字どおりに作り、同じ指示文で3回作った表紙が3枚とも文字・数字・配色どおりになる

## 段と判定（基礎＋独立採点。すべて○✖）

基礎が✖なら0点。基礎が○なら、そこから先の段は互いに独立に判定し、○になった段の点を合計する。段5（旧: 「2ページ目のB2・B4・B5・B3と棒グラフ4本」）と段10（旧: 「表紙3枚が文字・数字・配色どおり」）は、シートの数字とCanvaの絵、あるいは内容の正しさと配色という別の対象を1点・2点にまとめていたので、それぞれ5a/5b・10a/10bに分けた。段9（旧: 「B6・B7＋動画の縦横比」）と段11（旧: 「投稿文＋捏造なし」）も同様に分けた。分けた段の点の合計はもとの点のままで、そのぶん基礎の点を4→3に下げた（合計は変えていない）。

## 番号版・丸投げ・コピー・弱点

- 場面（4）・時間（9マス）・投稿時間帯（6）・GA4 のユーザー最多（3）を番号で回す。40版の正解の組はすべて違う。トレンドの表は全員同じ（言葉は全員「バイト」）
- 丸投げ: 材料を全部AIに貼ると、表2・表3の平均を比べたり、セッションで選んだりしやすい【未検証】。数字を誤ると、その数字に依存する段（2・3・4・5a・5b・6・7・8・9a・11a）が個別に✖になる。フォーム・表紙・Canva は本人の手が要るので、段1・9b・10a・10b は独立に通り得る
- コピー: 他人の数字は、データに依存する段（2〜9a・11a）が軒並み✖になる。表紙の言葉（段4の「バイト」）だけは全員同じなので写せる【弱点】が、B3・B5 は番号ごとに違うため段4自体はやはり✖になる
- 【曖昧】Googleトレンド・GA4 をスマホで見られるかは公式ヘルプで未確認。課題では教員が PC で取った写し（ここでは架空の数字）を渡す。授業の練習では、トレンドは PC の画面を映して見せる／GA4 は公式デモアカウントを教員の PC で見せる
- 【曖昧】Canva の MP4 ダウンロードは公式ヘルプで無料版でも可（既定の1080p）。スマホのアプリで同じ手順かは未確認。Canva のグラフ素材を無料版で使えるか未確認（使えなければ図形で棒を描く）
