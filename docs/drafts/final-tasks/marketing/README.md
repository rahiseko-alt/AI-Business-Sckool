# マーケティング 最終課題（成果物5、上限30点）— 教員用

作成日: 2026-09-28。状態: 下書き（未承認）。数字は `make_versions.py` で作り、`verify.py` で別の書き方で数え直して一致を確かめた。

## 1. 一本線と100点の定義

- マーケティング＝商談力＝**人の行動を変える**（`docs/knowledge/teacher/webライティング_PDF.md`: 誰の行動を → 何を伝える → どう伝える → どこで → 行動は変わった？）
- この課題はその流れをデータでつなぐ: **調査を作る → 集計する → 数字から「誰に・何を・いつ・どこで」を決める → カルーセル（SNSの5枚投稿）と投稿文を作る**
- 「好きな動画を作らせない」: 5枚の中身はすべて集計の数字から決まる。数字は学生ごとに違うので、好きに作った5枚・他人の5枚は段7から先で○にならない

**30点の人は**: 調べたいことに合う形式で調査フォームを作り、汚れた回答データを規則どおりに数え、その数字だけから「誰に・何を・いつ・どこで」を決めて、5枚すべてが数字と一致するカルーセルと投稿文を、70分で1つの誤りもなく作れる。

## 4. 本人がやった証拠

- **作業録画**（開始から提出まで）: 冒頭に合言葉。教員は冒頭と最後の10秒だけ見る。疑わしいときだけ中を見る
- **版の履歴**: スプレッドシート・スライドは70分時点の版で採点。コピーの作成時刻が開始後であること
- **合言葉の3点一致**: 録画の冒頭、シート B16、カルーセル5枚目。事前に作った物・他人の物はここで合わない
- 共有の記録: フォーム・シート・スライドの共有相手に教員以外の学生がいれば、その学生と両方を0段（基礎✖）にする【未承認】

## 7. 番号版の作り方

- `python3 make_versions.py 40` で `data/responses-01.csv`〜`40` と正解表を作る。乱数の種は番号なので、何度作っても同じ。年度を変えるときは `SALT` を変える
- 番号ごとに、場面（4種）・時間帯（9マス）・投稿先（3種）・投稿時間帯（6種）を回し、人数と除外行は乱数で変える。40版の正解の組はすべて違う
- 作った後は必ず `python3 verify.py` を実行する（別の書き方で数え直し、正解表と照合）

## 8. AIに丸投げした学生は何段で止まるか（見込み、未検証）

- フォーム作成とスライド作成はAIが代わりにできないので、本人が手を動かせば段4（8点）までは届く
- 回答データをAIに貼って数えさせると、43〜51行の数え間違いと除外漏れで**段5〜6（8〜9点）で止まる**のが多いと見込む
- コードを実行できるAIで、材料Bも全部渡した場合は除外を正しくこなし得る。その先の罠5（ターゲットだけ）・罠8（星）・罠9（祝日）・罠7（LINE/X）のどれかで、**段7〜12（11〜20点）で止まる**と見込む
- 使う前に教員が Gemini 無料版で丸投げを試し、何段で止まるかを確かめること【未検証】

## 9. コピーした学生はどうなるか

- 他人の企画シート・スライドを写すと、番号ごとに数字が違うので**段5で止まる（8点）**。40人の全組み合わせで試算すると、8点止まりが91%、偶然 B1 が同じで9点が8%、10〜11点が1%。合言葉は全員同じなので、合言葉では見分けられない
- フォーム（段1〜2）と動画の形（段3〜4）はまねできる。ただし共有の記録と作業録画で分かる
- 計算方法（数式）だけを口で教え合うことは防げない（教室での監督と録画が頼り）

## 10. 残る弱点と【曖昧】

- **スマホでできるか**【曖昧: 実機で未確認】: フォームの「評価」「ファイルのアップロード」をスマホのブラウザで追加できるか（ファイルのアップロードは回答者のログインが必要になり、容量は作成者のドライブを使う）／スプレッドシートのアプリで集計の数式を70分で組めるか／スライドのアプリで再生しながら画面録画できるか／70分の画面録画のファイルの大きさ（ドライブの無料枠15GB）と、授業中に上げきれるか
- **カルーセル動画の意味**【曖昧】: 元案6の「カルーセル動画を提出」を、ここでは「スライドを1枚ずつ送る様子を画面録画した動画」と解釈した。実際のSNSへの投稿は、公開と個人アカウントの危険があるので求めない。Google フォトで画像からスライドショー動画を作る方法もあるが、スマホのスライドのアプリで1枚ずつ画像に書き出せるか未確認のため採らなかった
- SNSの枚数の上限（Instagram・TikTok・Facebook は5枚以上可、X は4枚まで）は変わり得る。課題では材料Bのルールとして教員が固定した【曖昧: 一次情報で未確認】
- **リテラシーの最終課題と一部が重なる**: リテラシー案も申込フォームの回答から「テスト送信」「締切後」を除く。重なる罠を片方に寄せるか、利用者の判断が要る
- 段は下から順に止めるので、段1〜4の小さなミス（禁止語1つなど）で上の段が全部見られない。厳しすぎるなら「上の段は独立に数える」方式もあり得る【未承認】
- 投稿文の「順番が骨子どおりか」は読み手の判断が少し入る
- 教員が70分時点の版を見るには、フォーム・シート・スライドの編集者に入る必要がある
