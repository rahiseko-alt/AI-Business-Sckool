# マーケティング 最終課題（成果物5、上限25点）と成果物1〜4 — 教員用

作成日: 2026-09-28。状態: 下書き（未承認）。数字はすべて python で作り、別の書き方で数え直して一致を確かめた（`verify.py`・`verify_practice.py`）。

## 1. 一本線と25点の定義

- マーケティング＝**人の行動を変える**（`docs/knowledge/teacher/webライティング_PDF.md`: 誰の行動を → 何を伝える → どう伝える → どこで → 行動は変わった？）
- 5つの成果物は、どれも同じ**一連の仕事**: 調査を作る → 回答を数える → 数字から「誰に・何を・いつ・どこで」を決める → カルーセル（SNSの複数ページの投稿）を作って動画で出す
- らせん: 1→5で、設問の形式・行数・罠・データの種類・条件を増やし、時間を延ばす（下の表）。上限も課題ごとに上がる（8・12・15・20・25、合計80点）。最終課題だけを高得点にしない
- 「好きに作らせない」: ページの中身はすべて数字から決まり、数字は学生ごとに違う。好きに作った物・他人の物は数字の段で○にならない

**25点の人は**: 調べたいことに合う形式で調査フォームを作り、汚れた回答データを規則どおりに数え、その数字だけから「誰に・何を・いつ・どこで」を決めて、5ページすべてが数字と一致するカルーセルと投稿文を作り、同じ指示文で3回作った表紙を3回とも条件どおりにでき、これを70分で1つの誤りもなくやり切れる。

## 7. 段と判定（基礎＋独立採点。すべて○✖）

基礎が✖なら0点で、それより先は何も見ない（提出そのものが本人のものと確かめられないため）。基礎が○なら、そこから先の段はすべて**互いに独立**に判定し、○になった段の点をすべて合計する。段の順番に意味はなく、どれか1つ（または複数）が✖でも、ほかの段の点はそのまま残る。

## 9. AIに丸投げした学生は何点になるか（見込み、未検証）

- フォーム・表紙・Canva はAIが代わりに作れないので、本人が手を動かせば基礎＋段1〜4（8点）はほかの段の出来と無関係に確保できる
- 回答データをAIに貼って数えさせると、43〜51行の数え間違いと除外漏れで**段5・6（B1・B2）が✖になりやすい**。B1・B2 がずれると、そこから数字を引き継ぐ段7〜12・14bも連鎖してずれやすいため、8点（基礎＋段1〜4）前後に留まりやすいと見込む
- コードを実行できるAIに材料Bも全部渡した場合、除外はこなし得る。その先のターゲットの絞り込み・「いいえ」の星・祝日・LINE と X・棒グラフのどれかを外すと、**その段の点だけを独立に失う**（ほかの段の点は残る）。表紙を1回しか確かめない人は段13（2点）を丸ごと落とすが、段5〜12・14が○ならその点は入るので、最終的な点は「どの段を落としたか」の組み合わせで決まる
- 使う前に教員が Gemini 無料版で丸投げを試し、何点になるかを確かめること【未検証】

## 10. コピーした学生はどうなるか

- 他人の企画シート・カルーセルを写すと、番号ごとに数字が違うので、数字に依存する段（5・6・7・8a・8b・9・10・11・12a・12b・14b）が軒並み✖になり、**基礎＋段1〜4の8点に留まりやすい**。40人の全組み合わせ（1560通り）で、正解表のセルが偶然一致する段を数えると、8点止まりが59%、9点が27%、10点が7%、11〜13点が6%（独立採点なので、偶然に数字が一致した段の点だけがそのぶん上乗せされる。一致しやすいのは段6の B2 16%、段12a の投稿先・時間帯 15%、段5の B1 10%、段11の日時 9%）。改訂3で数え直した（旧版の「8点止まり91%」は B1 以外の偶然の一致を数えていなかった）
- 表紙の指示文は写せても、中の文字と数字が番号ごとに違うので、写しただけでは段7・13・14a が✖になる
- フォーム（段1〜2）と動画の形（段3〜4）はまねできる。共有の記録と作業録画で分かる

## 12. 共通の階段（5層、仮説）を当てた結果

`docs/drafts/tool-map-and-ladder.md` の5層を、段の条件を歪めずに当ててみた。段の条件は、課題にとって自然な形（上の表）のまま。

| 層 | 当てはまり | 理由 |
| --- | --- | --- |
| 基礎（届く） | ○ 全成果物 | 教員のアカウントへの共有・提出フォームで届く |
| ① 正確（条件・事実・誤字数字） | ○ だいたい合う | 下の段（フォームの形式、ページの役割、禁止語、透かし）がこれに当たる。成果物1は上限8点（基礎4＋4段）なので、フォームの形式（①）に加えて、B1（テスト送信の罠）・B2とB3（最多の数え方）・2枚目の日時場所を別々の段にし、この仕事の中心（数えた数字が正しいか）も点になるようにした（改訂3） |
| ② 検証（罠・隠しテスト・証拠・時間） | △ 罠だけ合う | マーケの段5〜11はほぼ全部「罠を見抜いたか」で、②の1項目が7段分に広がる（独立採点なので、罠を1つ見抜けなくても、ほかの罠を見抜いた段の点は残る）。**隠しテスト**（採点で行を足す）は、この課題が求めていない「式で作る」を強いるので入れなかった（番号ごとに違うデータがその役をしている）。**証拠**は除外した行の一覧で作れる（正解表に「除外の内訳」がある）が、段を取るほどの重さはない。**制限時間**は技能ではなく提出の条件なので、独立した段の1つにはせず、「1分ごとに合計点から1点引く」方式にした（段の1つにすると、遅れがほかの段の出来と無関係に扱われてしまい、時間の条件が技能の点と同じ重さになってしまう） |
| ③ 連携（ツールがデータでつながる） | ✕ 合わない | 集計（スプレッドシート）→ デザイン（Canva）→ 表紙（Gemini）の間は、スマホの無料版では手で写すしかない（Canva とシートの自動連携は無料版・スマホで未確認）。「手で写していない」を○の条件にすると、スマホ完結では誰も取れない。代わりに「ページの数字がシートと一致する」を見ているが、これは①正確の意味に近い |
| ④ 再現（3回・別番号・手順書） | △ 3回だけ合う | 表紙を同じ指示文で3回、は自然に入る（段13・14a）。**別の番号でも**は、式で作った表でないと意味がない（上と同じ理由で入れなかった）。**手順書だけで他人が同じ物を作れる**は、2分の○✖にできない |
| ⑤ 最適 | △ 作れるが判断が入る | 例えば「1ページ40字以内・数字は2つまで・CTA は1つ」なら○✖にできる。ただ「最適」かどうかは教員の基準しだいで、今の段14（表紙の配色・レイアウト＋材料にない数字ゼロ）の方がこの課題では自然 |

まとめ: マーケの段は「①正確 → ②罠（たくさん）→ ④再現」の順で自然に並び、③連携は入らない。5層を全科目の物差しにするなら、③を「データの一貫（ページとシートが一致）」と読み替えるか、マーケでは③を飛ばすか、の判断が要る。
