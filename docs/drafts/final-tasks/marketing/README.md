# マーケティング 最終課題（成果物5、上限30点）と成果物1〜4 — 教員用

作成日: 2026-09-28。状態: 下書き（未承認）。数字はすべて python で作り、別の書き方で数え直して一致を確かめた（`verify.py`・`verify_practice.py`）。

## 1. 一本線と30点の定義

- マーケティング＝商談力＝**人の行動を変える**（`docs/knowledge/teacher/webライティング_PDF.md`: 誰の行動を → 何を伝える → どう伝える → どこで → 行動は変わった？）
- 5つの成果物は、どれも同じ**一連の仕事**: 調査を作る → 回答を数える → 数字から「誰に・何を・いつ・どこで」を決める → カルーセル（SNSの複数ページの投稿）を作って動画で出す
- らせん: 1→5で、設問の形式・行数・罠・データの種類・条件を増やし、時間を延ばす（下の表）
- 「好きに作らせない」: ページの中身はすべて数字から決まり、数字は学生ごとに違う。好きに作った物・他人の物は数字の段で○にならない

**30点の人は**: 調べたいことに合う形式で調査フォームを作り、汚れた回答データを規則どおりに数え、その数字だけから「誰に・何を・いつ・どこで」を決めて、5ページすべてが数字と一致するカルーセルと投稿文を作り、同じ指示文で3回作った表紙を3回とも条件どおりにでき、これを70分で1つの誤りもなくやり切れる。

## 5. 本人がやった証拠

- **作業録画**（開始から提出まで）: 冒頭に合言葉。教員は冒頭と最後の10秒だけ見る
- **版の履歴**: フォーム・スプレッドシートは70分時点の版で採点（版の履歴はスマホで見られるか【曖昧】なので教員が PC で見る）
- **合言葉の3点一致**: 録画の冒頭、シート B15、カルーセル5ページ目
- **提出は教員のアカウントに届く形**（編集者への追加・閲覧者での共有）。ドライブの「共有アイテム」から一覧で集計できる
- 共有相手に教員以外の学生がいれば、その学生と両方を0段にする【未承認】
- 怪しいとき（録画が途切れる、短時間で完成している等）は、**口頭で説明させるか、同じ操作をその場でさせる**（例: 別の番号のデータで B2 と表紙を10分で出させる）

## 8. 番号版の作り方

- `python3 make_versions.py 40`（最終）と `python3 make_practice.py 40`（成果物1〜4）。乱数の種は番号なので何度作っても同じ。年度を変えるときは `SALT` を変える
- 作った後は必ず `python3 verify.py` と `python3 verify_practice.py` を実行する（別の書き方で数え直して照合）
- 最終課題は、場面（4）・時間帯（9マス）・投稿先（3）・投稿時間帯（6）を番号で回し、人数と除外行は乱数。40版の正解の組はすべて違う

## 9. AIに丸投げした学生は何段で止まるか（見込み、未検証）

- フォーム・表紙・Canva はAIが代わりに作れないので、本人が手を動かせば段4（8点）までは届く
- 回答データをAIに貼って数えさせると、43〜51行の数え間違いと除外漏れで**段5〜6（8〜9点）で止まる**のが多いと見込む
- コードを実行できるAIに材料Bも全部渡した場合、除外はこなし得る。その先のターゲットの絞り込み・「いいえ」の星・祝日・LINE と X・棒グラフのどれかで**段7〜12（11〜20点）**、表紙を1回しか確かめない人は段13で止まる
- 使う前に教員が Gemini 無料版で丸投げを試し、何段で止まるかを確かめること【未検証】

## 10. コピーした学生はどうなるか

- 他人の企画シート・カルーセルを写すと、番号ごとに数字が違うので**段5で止まる（8点）**。40人の全組み合わせで試算すると、8点止まりが91%、偶然 B1 が同じで9点が8%、10〜11点が1%
- 表紙の指示文は写せても、中の文字と数字が番号ごとに違うので、写しただけでは段7で落ちる
- フォーム（段1〜2）と動画の形（段3〜4）はまねできる。共有の記録と作業録画で分かる

## 11. 残る弱点と【曖昧】

- **スマホでできるか**: フォームはブラウザで作れる（公式ヘルプ）。フォームの「評価」「ファイルのアップロード」をスマホで追加できるかは未確認【曖昧】。ピボットテーブルはスマホ不可なので手順は `COUNTIFS` にした。Canva の MP4 ダウンロードは無料版で可（公式ヘルプ、既定の1080p）だが、スマホのアプリでの手順は未確認【曖昧】。Canva のグラフ素材が無料で使えるか未確認（使えなければ図形で棒を描く）【曖昧】
- 70分の画面録画のファイルの大きさ（ドライブの無料枠15GB）と、授業中に上げきれるか【曖昧】
- **カルーセル動画の意味**: 元案6の「カルーセル動画」を、Canva の複数ページを MP4 で書き出したものと解釈した。実際のSNSへの投稿は求めない
- SNSの枚数の上限（X は4枚まで等）とサイズは変わり得る。課題では材料のルールとして教員が固定した【曖昧: 一次情報で未確認】
- Gemini 無料版の生成回数の上限は数値の記載がない。3回＋作り直しで足りるか事前に試す【曖昧】
- トレンド・GA4・マップ（成果物3・4）は、正解が変わらないよう教員が取った写しを渡す。ここでは架空の数字で作った
- **リテラシーの最終課題と一部が重なる**: リテラシー案も申込フォームの回答から「テスト送信」「締切後」を除く。重なる罠を片方に寄せるか、利用者の判断が要る
- 段は下から順に止めるので、段1〜4の小さなミスで上の段が全部見られない。厳しすぎるなら「上の段は独立に数える」方式もあり得る【未承認】
- 投稿文の「順番が骨子どおりか」、表紙の「紺」「真ん中でいちばん大きい」は、読み手の判断が少し入る
- 再挑戦（別の番号で1回など）の扱いは未定
