# AI演習（実践）3行の課題 採点表（下書き）

作成日: 2026-09-29。状態: 下書き（未承認）。課題文は `tasks-3line.md` の「AI演習（実践）」節。
作り方: ADR 0001 に従い、成果物ごとに「満点の完成形」を先に書き、そこから「何が欠けると1点失うか」を引き算で洗い出して段にした。

## 共通の決まり

- 配点: 基礎4点＋残りを1点ずつの段。上限は成果物1＝8点、2＝12点、3＝15点、4＝20点、5＝25点。
- 基礎が✖なら0点で、それより先は見ない（本人が出したものと確かめられないため）。
- 基礎が○なら、ほかの段はすべて**互いに独立**に○✖を決め、○の段の点を足す。段の順番に意味はない。
- 提出フォームに、各ファイル（ドキュメント・スプレッドシート・スライド）のリンクを1つずつ書かせる前提。
- 課題文に書いていないこと（材料・罠・隠しテスト）は条件に入れていない。課題文だけでは○✖が決まらない所には【曖昧】を付け、成果物ごとに「決めてほしいこと」に書いた。
- 時間は教員が1つの段を見る目安（秒）。
