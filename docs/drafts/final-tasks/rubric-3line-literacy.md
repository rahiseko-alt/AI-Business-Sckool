# ビジネス情報リテラシー 3行の課題 採点表（下書き）

作成日: 2026-09-29。状態: 下書き（未承認）。課題文は `tasks-3line.md` の「ビジネス情報リテラシー」節。

作り方（ADR 0001）: 各成果物で、先に「満点の完成形（完璧な提出物）」を書き、そこから「何が欠けると1点失うか」を引き算で洗い出して段にした。

共通の決まり:

- 基礎（4点）: 本人が提出した証拠がそろう。提出フォームで、各ファイル（ドキュメント・シート・フォーム・フォルダ）のリンクを出す前提。基礎が✖なら0点で、ほかの段は見ない。
- 基礎が○なら、残りの段はすべて互いに独立に○✖を決め、○の段の点を足す。1つの✖で、ほかの段の点は失わない。
- 1つの段で見ることは1つだけ。
- 課題文に書いていないこと（材料・罠・隠しテスト）は条件に入れていない。課題文だけでは○✖が決まらない所には【曖昧】を付け、表の下の「決めてほしいこと」に書いた。
- 時間は、教員が1つの段の○✖を決めるまでの目安（秒）。
