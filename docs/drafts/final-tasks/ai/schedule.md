## 4. 共通の階段（5層、仮説）を当てた結果

`docs/drafts/tool-map-and-ladder.md` の5層（基礎＝届く／①正確 段1〜3／②検証 段4〜7／③連携 段8〜10／④再現 段11〜13／⑤最適）を、成果物1〜5の段に当ててみた。課題は層に合わせて歪めていない。

### 無理なく当てはまる所

- 基礎＝「指定の形で教員のアカウントに届く」: 1〜5 すべてで自然に当てはまる
- ①正確: 誤字（段1）とスライドの形の約束（段2）は、どの成果物でも下の方に来る
- ③連携: 成果物3の段7（集計の停止日と納品メールの本文が一致）、成果物4の段10（集計・グラフ・スライド・メールの数字が一致）は「複数のツールがデータでつながる」に当たり、置き場所も層とほぼ同じ高さ

### 当てはまらない所

| 層 | 何が合わないか | どうしたか |
| --- | --- | --- |
| ①と②の境目 | 原文照合の課題では「正確（誤りゼロ）」と「罠を見抜く」は同じことになる。分けると同じ誤りを2回数える。自然な順は層ではなく「罠の難しさ」（誤字→形→数字・条件→旧版→脱落） | 罠の難しさ順に並べた |
| ②の「制限時間内」 | 時間は段ではなく、フォームやメールの送信時刻で判定する（各成果物自身の制限時間で、授業内だけ受け付ける小テストの規則とは別）。成果物1・2・最終課題は制限を過ぎた1分ごとに合計点から1点引く。成果物3・4は基礎の条件のまま【未統一】。最終課題の「60分以内」の段（⑤）は改訂3でなくした | 段にしない |
| ②の「確かめた証拠」 | 成果物3・5 の誤り一覧は当たるが、成果物1・2には自然な証拠物がない。作らせると仕事が1つ増える | 成果物1・2では段にしていない |
| ②の「隠しテスト」 | 丸投げを最も確実に落とす罠なので、置き場所は②（段4〜7）より上になる（成果物3は段8、4は段11、最終は段13） | 順番が逆 |
| ③の「手で写していない」 | スマホでは、スプレッドシートのグラフをスライドにリンクして貼る手順が【曖昧】。集計→スライド→メールは手で写すしかない | 「値が一致する」を○の条件にした |
| ③の「元を変えると全体に伝わる」 | 伝わるのは表の中（結果・件数）まで。スライドのグラフ（スクリーンショット）とメールには伝わらない | 隠しテストは表の中だけで見る |
| ④の「同じ条件で3回」 | 画像の3枚・スライドの再現2枚は、ありふれた課題に差をつける仕組みなので、成果物2から下の段（段3・段2）に入る。④（段11〜13）に置くと成果物4まで画像が点にならない | 順番が逆（下の段に入れた） |
| ④の「別の番号の材料でも満たす」 | 今の版の仕組み（版1〜4）で自然に作れる。例: 学生の表のコピーに別の版の CSV を貼り、その版の正解になるか。隠しテストの強い版 | 未採用。入れるなら成果物4の段11か最終課題の段13の候補 |
| ④の「手順書だけで他人が再現」 | 他人が要り、2分で○✖にできない | 使っていない |
| ⑤最適 | 最終課題の「60分以内」の段（旧段14）は、時間だけで取れる点なので改訂3でなくした。どの成果物にも⑤の段はない | 使っていない |

結論（案）: 5層は「上ほど難しい」の目安としては使えるが、この科目の課題では層の順番と罠の難しさの順番が一致しない所が3つある（隠しテスト、再現、時間。時間は段にしていない）。層を固定するより、各成果物で「罠の難しさ順」に並べ、層は後から対応表として付ける方が課題を歪めない。
