# 成果物3 課題文（学生に配る）

AI演習（実践） 成果物3（15点）。**授業中に一人で、50分**。AI（Gemini、Gemini Notebook、画像生成・編集）は使ってよい。スマホだけでできる。

## 依頼

つばさ国際ビジネス学院（架空）の事務室から頼まれました。
2階の面接練習室のルールが今年度から変わりました。先輩が AI で張り紙の下書きを作りましたが、ルールの原文と照らし合わせていません。
あわせて、10月の利用記録から、予約を止める人を出してほしいと頼まれています。
**正しいのは材料A（ルールの原文）だけ**です。原文の末尾の「改定の記録」は、古いルールの記録です。

| 作るもの | 道具 | 使う材料 |
| --- | --- | --- |
| 1. 張り紙 | Google ドキュメント | 材料A（原文）、材料B（下書き） |
| 2. 説明スライド3枚 | Google スライド | 材料A、材料D（条件カード） |
| 3. 違反の集計表と誤り一覧 | Google スプレッドシート | 材料A、材料B、材料C（利用記録） |
| 4. 画像3枚 | 画像ファイル（PNG か JPG） | 材料E（元の画像と条件カード） |
| 5. 納品メール | Gmail | 1〜4のリンクと、予約を止める人 |

材料は版ごとに中身が違います。**自分に配られた版**で作ってください。

## 1. 張り紙の約束

- 材料B の下書きを直して、張り紙にする
- 原文と違うこと、原文にないことを書かない。誤字をなくす

## 3. 集計表の約束（この形でないと○にならない）

- 配られたスプレッドシートを「コピーを作成」し、シート名を「記録」にする（中身は変えない）
- シート「結果」: A1「学籍番号」、B1「違反回数」、C1「予約停止の開始日」。A2〜A9 に M01〜M08
  - B列は違反の回数、C列は予約の停止が始まる日（2026-11-02 のような 年-月-日 の形）。停止にならない人は空欄
  - B列・C列は**式**で出す。教員は採点のとき、「記録」の一番下に**別の利用記録を何行か足して**、結果が正しく変わるかを確かめる
- シート「誤り一覧」: 下書きの誤りを1行1つ。A列＝下書きの文（そのまま書き写す）、B列＝どう違うか、C列＝正しい内容

## 4. 画像の約束

- 同じ条件で**3枚**作る。3枚とも条件を満たすこと
- ドライブに「成果物3_出席番号_合言葉_画像」フォルダを作り、3枚を入れる

## 5. 納品（メールの送信時刻が提出時刻）

1. ファイル名を「成果物3_出席番号_合言葉_張り紙」「…_スライド」「…_集計」にする（合言葉は開始の合図のときに黒板に書く）
2. 張り紙・スライド・集計表は教員のアカウントを**編集者**として共有する。画像のフォルダは**閲覧者**として共有する
3. Gmail で教員のアカウントにメールを送る
   - 件名: 「成果物3_出席番号_合言葉_納品」
   - 本文: 版、4つのリンク（画像はフォルダ）、「予約停止: 学籍番号 開始日」を停止になる人の数だけ1行ずつ（いなければ「予約停止: なし」）

## 本人がやった証拠・禁止

- ファイルは開始の合図より後に自分のアカウントで作ったものだけを認める
- 授業中は、人と話すこと、人とファイルや画面を見せ合うことを禁止する。怪しいときは、その場で口頭で説明するか、同じ操作をもう一度してもらう
- 報酬を受け取ること、学外の人に作ってもらうこと、実在の人の名前・顔・連絡先を入れることは禁止
