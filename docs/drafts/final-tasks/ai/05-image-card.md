# 材料E 画像の修正前画像（仕様書）と条件カード

## 1. 修正前画像の仕様（教員が授業の前に作る。学生には画像だけを配る）

教員が画像生成で1枚作り、PNG で Google ドライブの共有フォルダに置く。版A・版Bとも同じ画像。

| 項目 | 中身 |
| --- | --- |
| 形 | 横長 16:9 |
| 背景 | 赤茶色の壁 |
| 中央 | 銀色のロッカー（扉が縦3段×横4列＝12枚） |
| ロッカーの中 | 右上の扉が1つ開いていて、**スマートフォン**と**ノートパソコン**が白いケーブルで充電されている |
| ロッカーの上 | 湯気の出ている**コーヒーカップ**が1つ |
| 上部の文字 | 大きな黒い文字で「**充電は120分まで**」 |
| 人物 | 描かない（人の顔・手を入れない） |
| ロゴ | 実在の会社・製品のロゴを入れない（スマホ・パソコンは無地） |

教員向けの生成指示の例: 「横長16:9のイラスト。赤茶色の壁の前に、扉が3段4列の銀色のロッカー。右上の扉だけ開いていて、中で無地のスマートフォンと無地のノートパソコンが白いケーブルで充電されている。ロッカーの上に湯気の出たコーヒーカップ。画像の上部に大きな黒い日本語で『充電は120分まで』。人物とロゴは描かない。」
（文字が崩れた場合は、教員がスライドで文字を載せて PNG で書き出してよい。修正前画像は正確に作っておく）

## 2. 条件カード（学生に配る）

依頼: 張り紙に使うため、配られた画像を次の**5つの条件**に合うように直して、画像ファイル（PNG か JPG）で提出してください。

| 番号 | 条件 |
| --- | --- |
| 1 | 背景を**白**にする |
| 2 | **ノートパソコン**を消す（スマートフォンは残す） |
| 3 | **コーヒーカップ**を消す |
| 4 | 文字を「**充電は90分まで**」にする。一字も違わず、ほかの文字は入れない |
| 5 | 横長 16:9 のまま |

- どの道具を使ってもよい（Gemini の画像生成・編集、Google フォトの編集、Google スライドで文字を載せて画像として書き出す、など）
- **18歳未満の人へ**: 画像の編集機能は18歳以上でないと使えないことがある。その場合は、元の画像を見ながら、5つの条件に合う画像を**新しく生成**してよい。採点は同じ5条件で行う（元の画像と同じ構図でなくてよい）
- 人の顔、実在の会社・製品のロゴは入れない

（教員メモ: 年齢条件と、スマホの Google スライドから画像を書き出せるかは、授業の前に最新のヘルプと実機で確かめる【曖昧】）
