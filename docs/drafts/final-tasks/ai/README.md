## 4. AIに丸投げすると落ちる罠（正解は材料の中に決めてある）

## 6. 悪いシナリオ

### AIに丸投げした学生は何段で止まるか

- 課題文と下書きを Gemini に貼って「直して」だけ: 段1で止まる（5点）。Notebook のスライドをそのまま出すので段2が✖。形だけ手で直しても、原文を読ませていないので段4で止まる（7点）
- 原文と下書きを Notebook に入れて「違いを直して」: 段4・5は通りやすい。旧版の値（段6）か画像の文字（段7）で止まる見込み（9〜10点）。脱落（段8）はさらに通りにくい
- 集計を AI のチャットで数えさせて数字を打つ: たとえ段11まで来ても、段13で必ず止まる（23点）
- 救済ライン（成果物合計46）の例では成果物5は11点＝段7。丸投げで取れるのはその手前まで

### コピーした学生はどうなるか

- 他人のファイルを丸ごとコピー: 版の履歴の作成者・作成時刻が合わず基礎で✖（0点）
- 隣の答えを見て打ち直す: 隣は違う版なので、台数・保管日数（段4）と試験期間（段8・11）が合わない
- 去年の答えを持ち込む: 版の値と記録を毎年変えれば合わない（毎年の作り直しが必要）

### 残る弱点

- 同じ版の学生（斜めの席など）の間で答えを口頭で伝えると、段4以降も通る。教室での見回りに頼る
- 下から順に止める方式なので、集計表が得意でも画像の文字（段7）で止まると10点。段の順番は利用者の判断が要る【未定】
- 90分・スマホ・4つ同時は重い。成果物1〜4（`d1/`〜`d4/`）で同じ一連の仕事を、小さい形から練習しておく。手順は [d5-procedure.md](d5-procedure.md)、授業回への割り付けは [schedule.md](schedule.md)
- AI の性能が上がると、画像の日本語（段7）と脱落の発見（段8）の罠が効かなくなる。毎年、教員が自分で丸投げを試して罠を入れ替える
- 90分の画面録画はファイルが大きく、個人のドライブ容量と Wi-Fi の負荷が心配【曖昧: 実機で確かめる】。録画の途中停止を完全には見抜けない
- 学生は全員成人なので、画像編集の年齢条件（18歳以上）は問題にならない（利用者、2026-09-28）。スマホのスライドから画像を書き出せるかは【曖昧: 授業前に実機で確かめる】
- 張り紙の「足した情報」は、原文と食い違わない限り自由にしたので、E1〜E10以外の書き方の良し悪しは採点しない
