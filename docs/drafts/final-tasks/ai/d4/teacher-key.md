### 隠しテストのやり方（段11）

学生の表の**コピー**の「記録」の最終行の下に `teacher-hidden-v版.csv` の3行を貼る。1人だけが停止に変わり、ほかの7人は変わらない（9月の行を1行入れてあるので、月で絞っていない式はここでも崩れる）。「件数」は10月の2行分だけ増える。

## 3. スライドの中身（段4・5・9）

| 中身 | ○に必要 | 1つでもあれば✖ |
| --- | --- | --- |
| 場所と部屋数 | 3階、版の部屋数、1室2人まで | 6室 |
| 使える日と時間 | 平日9時〜18時、土日祝は不可、**版の点検日は終日不可** | 点検日がない（段9） |
| 予約 | 版の日数の日前から前日17時まで、当日不可。1か所だけ | 当日可 |
| 上限と延長 | 版の上限、次の予約がないとき・1回だけ・版の分数、上限の前に事務室へ | 120分、何回でも |
| 備品と飲食 | 照明とマイクは部屋（1か所だけ）、イヤホンは各自、飲食不可 | イヤホン貸出し、飲み物可 |
| 違反 | 上限を過ぎて退室、延長後が上限、ちょうどは違反でない | 2回で1か月 |
| 予約の停止 | 同じ月に3回、翌日から版の日数、月が変わると0回 | |
| 忘れ物 | 版の保管日数 | 3日間 |
| 10月の利用状況 | 部屋別の10月の件数が上の正解と一致するグラフ | 元のグラフの数字 |
