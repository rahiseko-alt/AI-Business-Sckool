## 2026-10-01 非エンジニアが検算できる成績資料を追加

**決めたこと**

- 出力は Excel 1ファイル。シートは 説明・成績表・検算・完全性・根拠・採点ルール・確認事項
- 「検算」シートは元の値・扱い・根拠のセル・計算式（ふつうの式とExcel式）を並べ、
  Excelが計算した値とシステムの値の一致・不一致を表示する。値は丸めず、割り切れない値は分数で示す
- Excel が開けない環境向けに、同じ内容を縦に並べた HTML / PDF も出す（利用者のアプリで Excel が見えなかったため）
- 見本は架空データで `docs/sample/` に xlsx・html・pdf。LibreOffice で再計算し、全判定が「一致」になることをテストで確認
- テスト124件すべて通過

**次にやること**

- 利用者に見本を見てもらい、見方・項目・並びの修正点を聞く
- 資料が届いたら読込を作り、見本と同じ形で本番の成績資料を出す

**未解決の問題**

- 再計算のテストには LibreOffice の表計算部品が要る。作業環境に無ければそのテストだけ飛ばされる
- 人が端数を調整した後の評価を、システムで判定し直すかは未定

## 2026-10-01 資料に依存しない処理を実装

**決めたこと**

- 資料がまだ無いため、架空データで作れる部分を先に作った：氏名の正規化、学生の照合、
  科目ごとの採点ルール、計算と評価変換、元の値からの検算、学生×科目の完全性、完成可否の判定、元セルへの逆引き
- 計算は誤差の出ない厳密な分数で行う（小数誤差で60点が59点になる不具合を独立点検で発見し修正）
- 利用者の指示で、システムは一切丸めない。小数点は最終的に人が調整する。評価は丸めない合計で判定し、
  人の端数調整で評価が変わり得るものは WARNING として知らせる
- 空欄はルールで一律に点を与えられない。1件ずつ回答で意味を決める
- 学籍番号は大文字小文字を区別、メールは区別しない。互換漢字（神/神）は別名扱い
- テスト116件すべて通過。独立した確認役による点検2回で、見つかった問題はすべて修正済み

**次にやること**

- 資料（または個人情報を伏せた見本）を `data/input/` に置いてもらう
- 資料を見て、読込（資料の登録・抽出・根拠のセル番地）を作り、今回の部品と工程の進行役・保存の表をつなぐ
- 最終出力の形（Excel 等）を利用者に確認する

**未解決の問題**

- 人が端数を調整した後の評価を、システムが付けた評価と突き合わせる仕組みは無い
- WARNING（表記だけ違う一致）は人の確認なしで完成扱いになる。仕様どおりだが、監査一覧への表示はまだ未実装
- 各部品はまだ保存の表・工程の進行役とつながっていない
