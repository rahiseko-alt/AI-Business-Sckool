## 2026-10-05 後期バージョン（別案件）の方針を相談中

**決めたこと**

- 前期とは別案件「後期バージョン」。参照する資料が変わり得るのでゼロから考えてよい。目標は手間を最小にすること
- 道具は Google ドライブ（とスプレッドシート）。学務システムは無く、Classroom はあるが使っていないので使わない前提
- 先生のこだわりが強いので「入り口は先生ごとに自由、全員同じ形の『提出用の表』を科目ごとに1枚挟み、出口の成績表で自動集計」する
- 出席簿は事務などが1つにまとめて付ける指定フォームだが、形や式はよく変わる。こちらは出席簿の中身に頼らず、間に「出席の受け口」（学籍番号×科目の授業数・欠席・遅刻）を置き、出席簿が変わったらそこへのつなぎだけを直す。手打ちでも動く
- 配点（出席・態度・テストの点の配分）は先生ごとに決め、提出用の表の「配点」行に書く
- 評定の基準（A〜E の境目）は全科目共通。利用者が「設定」の欄に入力する
- セルの色の決まり: 黄＝人が入力、白＝式でロック、赤＝要確認。正常なら黄と白だけ
- 自動と手打ちの両立は「白の自動列＋黄の手入力列」を並べ、黄に数字があればそれを使う（白は上書きさせない）

**次にやること**

- 後期バージョンの `/grill-with-docs` の続き（提出の締め切りと確定のしかた、通知表の出し方、先生への権限など）
- 前期の Excel 版（rahiseko-alt/sirabasu#8）は `/to-tickets` 待ちのまま

**未解決の問題**

- 先行事例の調査では、市販の学務システム・Classroom の重み付け・差し込み印刷の追加機能（Autocrat）を見た。通知表の条件つき見た目（E の黒塗り・不合格印）を差し込み印刷で出せるかは未確認

## 2026-10-05 通知表を Excel の中で式で作る方針を決定（grill 完了）

**決めたこと**

- AI やプログラムを使わずに誰でも使えるよう、成績表の Excel ファイルに「通知表_全員」「通知表_1人」「成績証明書_1人」「例外」「特記事項」「確認」のシートを足し、成績表と出席簿を参照する式で作る（ADR 0002）
- Excel を使う。直すのは成績表の1ファイルだけ。人数は前期の60人で固定。後期の欄は空欄のまま
- 見た目は今のPDFと同じ（E の行と不合格印は黒地白文字）。不合格印は E か例外処置の F が1つでもあれば出す
- 発行日はファイルを開いた日（自動）。特記事項は学生ごとに書ける（無ければ「該当なし」）
- 成績表の欠けや矛盾は「要確認」と出し、「確認」シートの件数が0になってから印刷する
- 土台は 10.02 第2版に、筆記テストの訂正2件（AIBC26001・AIBC26004）とタパ ハルカの例外処置（日本語能力強化演習を F）を入れたもの
- 用語は `CONTEXT.md` に記録した

**次にやること**

- 仕様は rahiseko-alt/sirabasu#8 に作成済み（確かめ方は「作ったファイルを再計算して read_cards と全員分照合」で利用者了承）
- 次は `/to-tickets` で作業指示書に分ける → `/implement`
- 渡す前に、式の結果をプログラムの計算と全員分照合する（LibreOffice の表計算をこの作業環境に入れたので再計算できる。作業環境が作り直されたら `apt-get install -y libreoffice-calc` が要る）

**未解決の問題**

- 出席時数は今の出席集計（7科目）では足りないので、12科目分を出席簿から数える式を足す必要がある
- 「不合格印」を Excel で黒地白文字の枠として出す具体的な形は、作ってみて確認する
- GPA→ABCDE の基準: 利用者の回答待ち
