## 2026-10-05 通知表を Excel の中で式で作る方針を決定（grill 完了）

**決めたこと**

- AI やプログラムを使わずに誰でも使えるよう、成績表の Excel ファイルに「通知表_全員」「通知表_1人」「成績証明書_1人」「例外」「特記事項」「確認」のシートを足し、成績表と出席簿を参照する式で作る（ADR 0002）
- Excel を使う。直すのは成績表の1ファイルだけ。人数は前期の60人で固定。後期の欄は空欄のまま
- 見た目は今のPDFと同じ（E の行と不合格印は黒地白文字）。不合格印は E か例外処置の F が1つでもあれば出す
- 発行日はファイルを開いた日（自動）。特記事項は学生ごとに書ける（無ければ「該当なし」）
- 成績表の欠けや矛盾は「要確認」と出し、「確認」シートの件数が0になってから印刷する
- 土台は 10.02 第2版に、筆記テストの訂正2件（AIBC26001・AIBC26004）とタパ ハルカの例外処置（日本語能力強化演習を F）を入れたもの

**次にやること**

- 仕様は rahiseko-alt/sirabasu#8 に作成済み（確かめ方は「作ったファイルを再計算して read_cards と全員分照合」で利用者了承）
- 次は `/to-tickets` で作業指示書に分ける → `/implement`
- 渡す前に、式の結果をプログラムの計算と全員分照合する（LibreOffice の表計算をこの作業環境に入れたので再計算できる。作業環境が作り直されたら `apt-get install -y libreoffice-calc` が要る）

**未解決の問題**
