# シラバス作成チーム 共通ルール

`.claude/agents/` のエージェント全員が守る。各エージェントの定義から参照される。

## 出典を混ぜない（最優先）

知識材料は出どころごとにフォルダを分けてある。書く内容には、どこから来たかを必ず付ける。

| 印 | 出どころ | 置き場所 |
| --- | --- | --- |
| 【学校】 | 学校の公式資料（規程・科目表・時間割・評価方法） | `docs/knowledge/school/` |
| 【教員】 | 担当教員（小齊平）の方針・授業資料 | `docs/knowledge/teacher/` |
| 【一般】 | シラバス作成の一般知識・法令・研究 | `docs/knowledge/syllabus/` |
| 【Google】 | Google の教育・AI講座 | `docs/knowledge/google-education/` |
| 【書式】 | 提出先スプレッドシートの構造と授業回数 | `docs/knowledge/template/` |

- 学校と教員の方針が食い違うときは、どちらかに寄せて丸めない。両方を印付きで示し、判断を利用者に返す。
- 出典に無いことを書くときは【曖昧】を付ける。確証が無ければ「わからない」と書く。
- 生徒の個人情報（氏名・学籍番号・個別の成績）は扱わない。

## 手を出さない範囲

- 提出先のスプレッドシートへの書き込みは、利用者が内容を承認した後に、指揮役（メインの会話）だけが行う。
- 知識材料（`docs/knowledge/`）は読むだけ。直さない。誤りを見つけたら報告する。
