# 0003 後期は Google スプレッドシートで「先生ごとの提出用の表 → 成績表」に集める

- 状態: 採用
- 日付: 2026-10-06

前期は先生ごとに形の違う採点表と出席簿を、こちらで読み解いて手直ししていたため手間が大きかった。後期は学務システムや Classroom（あるが使われていない）に乗らず、Google ドライブ上のスプレッドシートで作る。先生のこだわりが強く、縛りの強い道具は使われなくなるため、先生の採点のしかたは自由のまま、科目ごとに全員同じ形の**提出用の表**（配点・出席・態度・テスト・提出済み）を1枚だけ挟み、**成績表**がそれを集める。出席簿は形がよく変わるので、成績表は出席簿を直接読まず**出席の受け口**だけを見る。

## 結果

- 前期の Excel 版（ADR 0002）とは別のファイル・別の道具になる。前期の成績は値として一度だけ写し、前期ファイルにはつながない。
- 自動と手打ちを両立させるため、白（式・ロック）の自動列と黄（人が入力）の手入力列を並べる。赤は要確認。正常なら黄と白だけ。
- 個人のドライブで作ってから学校のアカウントへコピーで移す前提なので、ファイル間のつなぎ先は成績表の「設定」の一覧1か所に集め、移したらそこを貼り直す。
