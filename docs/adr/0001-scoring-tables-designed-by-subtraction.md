# 採点表は満点の完成形から引き算で設計する

積み上げ式（独立した観点ごとに採点し、できた分だけ加算する）の採点表を、下から項目を足し算で並べる手順で作ると、
観点の抜け・重複・配点の整合崩れが起きる（実例: AI演習・成果物1の旧設計。段を順番に積み上げる形で作った結果、
本来は独立のはずの4観点が1つの段に束ねられ、1つの小さな✖で他3つの得点まで失う欠陥になった）。

そのため、採点表を作るときは必ず**満点の完成形（完璧な提出物とは何か）を先に定義し、そこから「何が欠けると
何点失うか」を引き算で洗い出す**手順を取る。結果としてできあがる採点表は積み上げ（加算）式になるが、
設計の手順自体を足し算（下から項目を思いつくたびに追加する）で進めると、積み上げ式の課題は正しく作れない。

この手順は、マーケ・AI演習の段テーブルの作り直し、および今後のリテラシー成果物1〜4の新規設計すべてに適用する。
