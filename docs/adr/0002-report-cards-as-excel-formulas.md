# 0002 通知表・成績証明書は成績表の Excel の中に式で作る

- 状態: 採用
- 日付: 2026-10-05

通知表は当初、プログラム（`scripts/build_report_cards.py`）が成績表を読んで PDF を作っていたが、それでは AI かプログラムを動かせる人を通さないと通知表にならない。利用者の求めは「誰でも、成績表の数字を直せば印刷まで自動で反映される」ことなので、通知表・成績証明書・例外処置・特記事項・確認を、成績表の Excel ファイルの中のシートとして、成績表と出席簿を参照する式で作る。Google スプレッドシートではなく Excel にしたのは、利用者が普段 Excel で開いて直すため。

## 結果

- ADR 0001 の「出力のたびに検算し、食い違えば止める」は、Excel の中では自動では働かない。代わりに、ファイルを渡す前に一度だけ、式の結果をプログラムの計算（`report_card.py`）と全員分照合する。その後の修正は「確認」シートの「要確認」件数で見張り、件数が0になるまで印刷しない運用にする。
- 例外処置は成績表の点数を書き換えず、「例外」シートに理由とともに1行で記録する（ADR 0001 の「修正は元の値を残して別に記録する」に合わせる）。
- 学生の人数は前期の60人で固定する。入れ替わりや後期の追加には、シートの作り直しが要る。
